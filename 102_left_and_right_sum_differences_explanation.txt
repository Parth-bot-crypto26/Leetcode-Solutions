===================================================================
LEETCODE 2574: LEFT AND RIGHT SUM DIFFERENCES
===================================================================

[PROBLEM DESCRIPTION]
You are given a 0-indexed integer array 'nums' of size 'n'.
Define two arrays 'leftSum' and 'rightSum' where:
- 'leftSum[i]' is the sum of elements to the left of index 'i' in 'nums'. If there is no such element, 'leftSum[i] = 0'.
- 'rightSum[i]' is the sum of elements to the right of index 'i' in 'nums'. If there is no such element, 'rightSum[i] = 0'.

Return an integer array 'answer' of size 'n' where 'answer[i] = |leftSum[i] - rightSum[i]|'.

Constraints:
- 1 <= nums.length <= 1000
- 1 <= nums[i] <= 10^5

-------------------------------------------------------------------
[METHODOLOGY: PREFIX AND SUFFIX SUM ACCUMULATION (O(N) TIME, O(N) SPACE)]
-------------------------------------------------------------------

The problem requires calculating the absolute difference between the total sum of elements preceding each index and the total sum of elements following each index.

1. LEFT SUM COMPUTATION (FORWARD PASS):
   - Maintain a running accumulator 'currLeftSum = 0'.
   - Iterate through 'nums' from left to right (index 0 to n - 1):
     * Store the current value of 'currLeftSum' in 'left[i]'.
     * Add 'nums[i]' to 'currLeftSum' to include it for subsequent indices.

2. RIGHT SUM COMPUTATION (BACKWARD PASS):
   - Maintain a running accumulator 'currRightSum = 0'.
   - Iterate through 'nums' from right to left (index n - 1 down to 0):
     * Store the current value of 'currRightSum' in 'right[i]'.
     * Add 'nums[i]' to 'currRightSum' to include it for preceding indices.

3. ABSOLUTE DIFFERENCE CALCULATION:
   - Perform a final pass to compute 'ans[i] = |left[i] - right[i]|' for each index 'i'.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [10, 4, 8, 3] | n = 4

- Forward Pass (Computing leftSum):
  * i = 0: left[0] = 0  | currLeftSum becomes 0 + 10 = 10
  * i = 1: left[1] = 10 | currLeftSum becomes 10 + 4 = 14
  * i = 2: left[2] = 14 | currLeftSum becomes 14 + 8 = 22
  * i = 3: left[3] = 22 | currLeftSum becomes 22 + 3 = 25
  * Resulting left array: [0, 10, 14, 22]

- Backward Pass (Computing rightSum):
  * i = 3: right[3] = 0  | currRightSum becomes 0 + 3 = 3
  * i = 2: right[2] = 3  | currRightSum becomes 3 + 8 = 11
  * i = 1: right[1] = 11 | currRightSum becomes 11 + 4 = 15
  * i = 0: right[0] = 15 | currRightSum becomes 15 + 10 = 25
  * Resulting right array: [15, 11, 3, 0]

- Absolute Difference Pass:
  * ans[0] = |0 - 15|  = 15
  * ans[1] = |10 - 11| = 1
  * ans[2] = |14 - 3|  = 11
  * ans[3] = |22 - 0|  = 22

Returns [15, 1, 11, 22].

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n)
- Explanation: Where 'n' is the length of 'nums'. The algorithm performs three sequential 
  linear iterations over the array, running in total O(n) time.

Space Complexity: O(n)
- Explanation: Requires auxiliary memory vectors ('left', 'right', 'ans') each of length 
  'n' to store intermediate prefix and suffix sums.
