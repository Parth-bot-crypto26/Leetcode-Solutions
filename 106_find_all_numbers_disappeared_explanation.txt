===================================================================
LEETCODE 448: FIND ALL NUMBERS DISAPPEARED IN AN ARRAY
===================================================================

[PROBLEM DESCRIPTION]
Given an array 'nums' of 'n' integers where 'nums[i]' is in the range [1, n], return an array of all the integers in the range [1, n] that do not appear in 'nums'.

Constraints:
- n == nums.length
- 1 <= n <= 10^5
- 1 <= nums[i] <= n
- Follow-up: Could you do it without extra space and in O(n) runtime? You may assume the returned list does not count as extra space.

-------------------------------------------------------------------
[METHODOLOGY: IN-PLACE NEGATION MARKING (O(N) TIME, O(1) SPACE)]
-------------------------------------------------------------------

A extra hash set approach takes O(N) space. To satisfy the O(1) auxiliary space requirement, we utilize the input array itself as a hash table by exploiting the property that values are within [1, n].

1. IN-PLACE MARKING PASS (FORWARD PASS):
   - Iterate through 'nums' from index 0 to 'n - 1':
     * Treat the magnitude 'abs(nums[i])' as a 1-based value and compute its corresponding index: 'targetIdx = abs(nums[i]) - 1'.
     * Mark the presence of this value by negating the element at 'nums[targetIdx]' if it is currently positive ('nums[targetIdx] = -nums[targetIdx]').

2. DISAPPEARED NUMBERS IDENTIFICATION PASS:
   - Iterate through 'nums' a second time from index 0 to 'n - 1':
     * IF 'nums[i] > 0': The value 'i + 1' was never encountered during the first pass, meaning it is missing.
     * Append 'i + 1' to the result vector 'ans'.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [4, 3, 2, 7, 8, 2, 3, 1] | n = 8

- Pass 1 (In-Place Negation):
  * i = 0, num = 4 -> targetIdx = 3 | nums[3] (7) becomes -7 | nums = [4, 3, 2, -7, 8, 2, 3, 1]
  * i = 1, num = 3 -> targetIdx = 2 | nums[2] (2) becomes -2 | nums = [4, 3, -2, -7, 8, 2, 3, 1]
  * i = 2, num = 2 -> targetIdx = 1 | nums[1] (3) becomes -3 | nums = [4, -3, -2, -7, 8, 2, 3, 1]
  * i = 3, num = 7 -> targetIdx = 6 | nums[6] (3) becomes -3 | nums = [4, -3, -2, -7, 8, 2, -3, 1]
  * i = 4, num = 8 -> targetIdx = 7 | nums[7] (1) becomes -1 | nums = [4, -3, -2, -7, 8, 2, -3, -1]
  * i = 5, num = 2 -> targetIdx = 1 | nums[1] is already -3  | unchanged
  * i = 6, num = 3 -> targetIdx = 2 | nums[2] is already -2  | unchanged
  * i = 7, num = 1 -> targetIdx = 0 | nums[0] (4) becomes -4 | nums = [-4, -3, -2, -7, 8, 2, -3, -1]

- Pass 2 (Scanning Positive Indices):
  * Index 0: nums[0] = -4 (Negative -> 1 is present)
  * Index 1: nums[1] = -3 (Negative -> 2 is present)
  * Index 2: nums[2] = -2 (Negative -> 3 is present)
  * Index 3: nums[3] = -7 (Negative -> 4 is present)
  * Index 4: nums[4] =  8 (Positive -> 5 is MISSING) -> Add 5
  * Index 5: nums[5] =  2 (Positive -> 6 is MISSING) -> Add 6
  * Index 6: nums[6] = -3 (Negative -> 7 is present)
  * Index 7: nums[7] = -1 (Negative -> 8 is present)

Returns [5, 6].

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n)
- Explanation: Where 'n' is the length of 'nums'. The algorithm performs two sequential linear passes over the array.

Space Complexity: O(1) Auxiliary Space
- Explanation: Reuses the input array for state tracking via sign flipping. Per problem specification, the output list 'ans' is excluded from space complexity evaluation.
