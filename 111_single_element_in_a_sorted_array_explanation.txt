===================================================================
LEETCODE 540: SINGLE ELEMENT IN A SORTED ARRAY
===================================================================

[PROBLEM DESCRIPTION]
You are given a sorted array consisting of only integers where every element appears exactly twice, except for one element which appears exactly once.
Return the single element that appears only once.
Your solution must run in O(log n) time and O(1) space.

Constraints:
- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^5

-------------------------------------------------------------------
[METHODOLOGY: BINARY SEARCH ON INDEX PARITY (O(LOG N) TIME, O(1) SPACE)]
-------------------------------------------------------------------

A linear XOR or frequency check takes O(N) time. Because the array is sorted, we can use Binary Search based on the index parity (even/odd) of identical pairs.

1. PARITY INVARIANT PATTERN:
   - Before the single element, pairs always start at an EVEN index and end at an ODD index:
     * (even, odd) -> (0, 1), (2, 3), (4, 5)...
   - After the single element, the pattern flips. Pairs start at an ODD index and end at an EVEN index:
     * (odd, even) -> (3, 4), (5, 6), (7, 8)...

2. EDGE CASES & BASE HANDLING:
   - If 'n == 1', return 'nums[0]'.
   - In the binary search loop:
     * Check boundary conditions: if 'mid == 0' or 'mid == n - 1', return 'nums[mid]' if it doesn't match its adjacent element.
     * Check single element condition: IF 'nums[mid - 1] != nums[mid]' AND 'nums[mid] != nums[mid + 1]', then 'nums[mid]' is the unique element.

3. BINARY SEARCH DECISION LOGIC:
   - IF 'mid' is EVEN:
     * If 'nums[mid - 1] == nums[mid]': We are on the right side of the single element (pattern flipped). Search left ('end = mid - 1').
     * Else: We are on the left side (normal pattern). Search right ('st = mid + 1').
   - IF 'mid' is ODD:
     * If 'nums[mid - 1] == nums[mid]': We are on the left side of the single element (normal pattern). Search right ('st = mid + 1').
     * Else: We are on the right side (pattern flipped). Search left ('end = mid - 1').

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [1, 1, 2, 3, 3, 4, 4, 8, 8] | n = 9

- Initial State: st = 0, end = 8

- Iteration 1:
  * mid = 0 + (8 - 0) / 2 = 4 (nums[mid] = 3)
  * Check single condition: nums[3] = 3, nums[5] = 4 (nums[3] == nums[4], not single)
  * mid (4) is EVEN:
    - nums[mid - 1] == nums[mid] (nums[3] == nums[4] -> 3 == 3) is True!
    - We are in the right region -> end = mid - 1 = 3

- Iteration 2:
  * st = 0, end = 3 -> mid = 0 + (3 - 0) / 2 = 1 (nums[mid] = 1)
  * Check single condition: nums[0] = 1, nums[2] = 2 (nums[0] == nums[1], not single)
  * mid (1) is ODD:
    - nums[mid - 1] == nums[mid] (nums[0] == nums[1] -> 1 == 1) is True!
    - We are in the left region -> st = mid + 1 = 2

- Iteration 3:
  * st = 2, end = 3 -> mid = 2 + (3 - 2) / 2 = 2 (nums[mid] = 2)
  * Check single condition: nums[1] = 1, nums[3] = 3
    - nums[1] != nums[2] AND nums[2] != nums[3] (1 != 2 AND 2 != 3) -> True!
    - Single element found at mid = 2.

Returns 2.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

class Solution {
public:
    int singleNonDuplicate(vector<int>& nums) {
        int n = nums.size();
        int st = 0, end = n-1;
        if(n == 1) return nums[0];
        while(st <= end){
            int mid = st + (end-st)/2;
            if(mid == 0 && nums[0] != nums[1]) return nums[mid];
            if(mid == n-1 && nums[n-1] != nums[n-2]) return nums[mid];
            if(nums[mid-1] != nums[mid] && nums[mid] != nums[mid+1]){
                return nums[mid];
            }
            if(mid%2 == 0){
                if(nums[mid-1] == nums[mid]){
                    end = mid-1;
                }else{
                    st = mid+1;
                }
            }else{
                if(nums[mid-1] == nums[mid]){
                    st = mid+1;
                }else{
                    end = mid-1;
                }
            }
        }
        return -1;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(log n)
- Explanation: Where 'n' is the length of 'nums'. Half of the search space is eliminated during each iteration of the binary search.

Space Complexity: O(1)
- Explanation: Uses constant auxiliary space for pointers ('st', 'end', 'mid', 'n') allocated on the stack.
