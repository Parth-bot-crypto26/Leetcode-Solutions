===================================================================
LEETCODE 88: MERGE SORTED ARRAY
===================================================================

[PROBLEM DESCRIPTION]
You are given two integer arrays 'nums1' and 'nums2', sorted in non-decreasing order, and two integers 'm' and 'n', representing the number of elements in 'nums1' and 'nums2' respectively.
Merge 'nums1' and 'nums2' into a single array sorted in non-decreasing order.
The final sorted array should not be returned by the function, but instead be stored inside the array 'nums1'. To accommodate this, 'nums1' has a length of 'm + n', where the first 'm' elements denote the elements that should be merged, and the last 'n' elements are set to 0 and should be ignored.

Constraints:
- nums1.length == m + n
- nums2.length == n
- 0 <= m, n <= 200
- 1 <= m + n <= 200
- -10^9 <= nums1[i], nums2[j] <= 10^9
- Follow-up: Can you come up with an algorithm that runs in O(m + n) time?

-------------------------------------------------------------------
[METHODOLOGY: THREE-POINTER BACKWARD MERGE (O(M + N) TIME, O(1) SPACE)]
-------------------------------------------------------------------

A standard forward merge requires creating an auxiliary array of size O(m + n) to avoid overwriting elements in 'nums1'. To merge in-place with O(1) extra space, we place elements starting from the end of 'nums1' (where unused space exists).

1. THREE-POINTER SET UP:
   - 'i = m - 1': Points to the last valid element in 'nums1'.
   - 'j = n - 1': Points to the last element in 'nums2'.
   - 'idx = m + n - 1': Points to the last available position in the merged array 'nums1'.

2. BACKWARD COMPARISON PASS:
   - While both arrays have unmerged elements ('i >= 0 && j >= 0'):
     * Compare 'nums1[i]' and 'nums2[j]'.
     * Place the larger element at 'nums1[idx]'.
     * Decrement 'idx' and the pointer corresponding to the chosen element.

3. CLEANUP REMAINING ELEMENTS:
   - While 'j >= 0': If elements remain in 'nums2', copy them to 'nums1[idx]'.
   - Note: If elements remain in 'nums1' ('i >= 0'), they are already in their correct sorted positions at the front of 'nums1', so no extra loop is needed.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums1 = [1, 2, 3, 0, 0, 0], m = 3 | nums2 = [2, 5, 6], n = 3

- Initial State: i = 2 (val=3), j = 2 (val=6), idx = 5

- Iteration 1:
  * nums1[i] (3) vs nums2[j] (6) -> 6 is larger.
  * nums1[5] = 6 | idx = 4, j = 1

- Iteration 2:
  * nums1[i] (3) vs nums2[j] (5) -> 5 is larger.
  * nums1[4] = 5 | idx = 3, j = 0

- Iteration 3:
  * nums1[i] (3) vs nums2[j] (2) -> 3 is larger.
  * nums1[3] = 3 | idx = 2, i = 1

- Iteration 4:
  * nums1[i] (2) vs nums2[j] (2) -> nums1[i] >= nums2[j] (2 >= 2).
  * nums1[2] = 2 | idx = 1, i = 0

- Iteration 5:
  * nums1[i] (1) vs nums2[j] (2) -> 2 is larger.
  * nums1[1] = 2 | idx = 0, j = -1

First while loop terminates (j < 0).
Cleanup loop is skipped as j < 0.

Resulting nums1: [1, 2, 2, 3, 5, 6].

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int idx = n+m-1, i = m-1, j = n-1;
        while(i >= 0 && j >= 0){
            if(nums1[i] >= nums2[j]){
                nums1[idx] = nums1[i];
                idx--; i--;
            }else{
                nums1[idx] = nums2[j];
                idx--; j--;
            }
        }
        while(j >= 0){
            nums1[idx] = nums2[j];
            idx--; j--;
        }
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(m + n)
- Explanation: In each step of the algorithm, at least one pointer ('i' or 'j') is decremented. The total number of comparisons and assignments is bounded by (m + n).

Space Complexity: O(1)
- Explanation: The merge is performed completely in-place within 'nums1', utilizing constant auxiliary space for pointers ('idx', 'i', 'j').
