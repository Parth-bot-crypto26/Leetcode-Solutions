===================================================================
LEETCODE 31: NEXT PERMUTATION
===================================================================

[PROBLEM DESCRIPTION]
A permutation of an array of integers is an arrangement of its members into a sequence or linear order.
The next permutation of an array of integers is the next lexicographically greater permutation of its integer. If such arrangement is not possible, the array must be rearranged as the lowest possible order (i.e., sorted in ascending order).
Given an array of integers 'nums', find the next permutation of 'nums'.
The replacement must be in place and use only constant extra memory.

Constraints:
- 1 <= nums.length <= 100
- 0 <= nums[i] <= 100

-------------------------------------------------------------------
[METHODOLOGY: SINGLE-PASS PIVOT & SWAP (O(N) TIME, O(1) SPACE)]
-------------------------------------------------------------------

To find the next lexicographically greater permutation, we must increase the sequence by making the smallest possible modification from right to left:

1. FIND THE PIVOT INDEX:
   - Traverse the array backwards from 'n - 2' down to 0 to find the first element that violates the non-increasing sequence from the right: 'nums[i] < nums[i + 1]'.
   - Label this index as 'pivot'.

2. EDGE CASE (ENTIRE ARRAY IS DESCENDING):
   - If no such pivot exists ('pivot == -1'), the array is in its maximum lexicographical state (e.g., [3, 2, 1]).
   - Reverse the entire array to return it to the lowest possible order (ascending).

3. FIND THE NEXT GREATER ELEMENT & SWAP:
   - If a valid pivot is found, iterate backwards from 'n - 1' down to 'pivot + 1' to find the smallest element that is strictly greater than 'nums[pivot]'.
   - Swap 'nums[pivot]' with 'nums[i]'.

4. REVERSE THE SUFFIX:
   - The elements after 'pivot' are guaranteed to be in descending order.
   - Reverse the subarray from 'pivot + 1' to the end of the array to turn it into ascending order, minimizing the increase for the next permutation.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [1, 2, 3] | n = 3

- Step 1: Find Pivot
  * i = 1: nums[1] (2) < nums[2] (3) -> pivot = 1

- Step 2: Check Edge Case
  * pivot = 1 != -1 -> Proceed.

- Step 3: Find Swap Candidate & Swap
  * Traversal from right: i = 2 -> nums[2] (3) > nums[pivot] (2).
  * Swap nums[1] and nums[2] -> nums = [1, 3, 2]

- Step 4: Reverse Suffix
  * Reverse subarray from pivot + 1 (index 2) to end (index 2).
  * Subarray of length 1 remains unchanged.

Resulting nums: [1, 3, 2].

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int pivot = -1;
        for(int i = n-2; i >= 0; i--){
            if(nums[i] < nums[i+1]){
                pivot = i;
                break;
            }
        }
        if(pivot == -1){
            reverse(nums.begin(), nums.end());
            return;
        }
        for(int i = n-1; i > pivot; i--){
            if(nums[i] > nums[pivot]){
                swap(nums[i], nums[pivot]);
                break;
            }
        }
        reverse(nums.begin()+pivot+1, nums.end());
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n)
- Explanation: Where 'n' is the length of 'nums'. In the worst case, the algorithm performs two backwards linear scans and one reversal pass, taking linear time overall.

Space Complexity: O(1)
- Explanation: The array modification is done strictly in-place using constant auxiliary variables ('pivot', 'n', 'i').
