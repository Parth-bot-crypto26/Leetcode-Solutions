===================================================================
LEETCODE 125: VALID PALINDROME
===================================================================

[PROBLEM DESCRIPTION]
A phrase is a palindrome if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.
Given a string 's', return true if it is a palindrome, or false otherwise.

Constraints:
- 1 <= s.length <= 2 * 10^5
- 's' consists only of printable ASCII characters.

-------------------------------------------------------------------
[METHODOLOGY: TWO-PASS FILTER & REVERSE VS. TWO-POINTER (IN-PLACE)]
-------------------------------------------------------------------

Your provided solution builds a filtered string and compares it to its reverse. While it passes within limits, we can analyze both the two-pass string construction method and the optimal two-pointer approach:

1. TWO-PASS STRING FILTERING (YOUR APPROACH):
   - Iterate through 's', keeping only alphanumeric characters converted to lowercase using 'isalnum()' and 'tolower()'.
   - Store the filtered characters in a new string 'temp'.
   - Create a reversed copy of 'temp' and compare 'temp == reversed'.
   - Complexity: O(N) time, O(N) auxiliary space.

2. TWO-POINTER IN-PLACE APPROACH (OPTIMAL):
   - Maintain two pointers: 'st = 0' and 'end = s.length() - 1'.
   - Advance 'st' rightward while 's[st]' is non-alphanumeric.
   - Advance 'end' leftward while 's[end]' is non-alphanumeric.
   - Compare 'tolower(s[st])' with 'tolower(s[end])'. If they differ, return false.
   - Increment 'st' and decrement 'end' until pointers cross.
   - Complexity: O(N) time, O(1) auxiliary space.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: s = "A man, a plan, a canal: Panama"

- Filtering Pass:
  * Non-alphanumeric characters (spaces, commas, colons) are skipped.
  * Upper case characters are converted to lowercase.
  * Filtered string 'temp' = "amanaplanacanalpanama"

- Reverse Pass:
  * 'reversed' = "amanaplanacanalpanama"

- Comparison:
  * 'temp' == 'reversed' ("amanaplanacanalpanama" == "amanaplanacanalpanama") -> True.

Returns true.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Approach 1: Filter & Compare (Submitted Code)
class Solution {
public:
    bool isPalindrome(string s) {
        string temp = "";
        for(char c : s){
            if(isalnum(c)){
                temp += tolower(c);
            }
        }
        string reversed = temp;
        reverse(reversed.begin(), reversed.end());
        return temp == reversed;
    }
};

// Approach 2: Optimal Two-Pointer In-Place (O(1) Space)
class SolutionOptimal {
public:
    bool isPalindrome(string s) {
        int st = 0, end = s.length() - 1;
        while (st < end) {
            while (st < end && !isalnum(s[st])) st++;
            while (st < end && !isalnum(s[end])) end--;
            if (tolower(s[st]) != tolower(s[end])) return false;
            st++;
            end--;
        }
        return true;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Your Code (Filter & Reverse):
- Time Complexity: O(n) — Single pass to filter plus one pass to reverse and compare string of length <= n.
- Space Complexity: O(n) — Allocates auxiliary memory for the 'temp' and 'reversed' strings.

Optimal Two-Pointer Code:
- Time Complexity: O(n) — Performs a single pass inward from both endpoints.
- Space Complexity: O(1) — Operates directly on the input string using two index pointers.
