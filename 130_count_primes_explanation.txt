===================================================================
LEETCODE 204: COUNT PRIMES
===================================================================

[PROBLEM DESCRIPTION]
Given an integer 'n', return the number of prime numbers that are strictly less than 'n'.

Constraints:
- 0 <= n <= 5 * 10^6

-------------------------------------------------------------------
[METHODOLOGY: SIEVE OF ERATOSTHENES (O(N LOG LOG N) TIME, O(N) SPACE)]
-------------------------------------------------------------------

To count primes strictly less than 'n':

1. EDGE CASE HANDLING:
   - If $n \le 2$, return 0 immediately because there are no prime numbers strictly less than 2.

2. SIEVE INITIALIZATION:
   - Create a boolean array `isPrime` of size $n$, initialized to `true`.
   - Set `isPrime[0] = false` and `isPrime[1] = false`.

3. INNER LOOP OPTIMIZATION:
   - Iterate $i$ from 2 up to $\sqrt{n}$ (i.e., $i \cdot i < n$).
   - If `isPrime[i]` is `true`, start marking multiples beginning from $j = i \cdot i$ instead of $i \cdot 2$, because all smaller multiples $i \cdot 2, i \cdot 3, \dots, i \cdot (i-1)$ have already been marked by smaller prime factors.
   - Advance $j$ by $i$ in steps ($j += i$).

4. COUNTING:
   - After marking composite numbers, iterate through `isPrime` from 2 to $n - 1$ to sum up the remaining `true` values.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 10

- Initial State: isPrime = [F, F, T, T, T, T, T, T, T, T]
- Outer Loop Limit: i * i < 10 -> i loops for i = 2, 3

- i = 2 (Prime):
  * Mark multiples starting at j = 2 * 2 = 4:
    - isPrime[4] = F, isPrime[6] = F, isPrime[8] = F

- i = 3 (Prime):
  * Mark multiples starting at j = 3 * 3 = 9:
    - isPrime[9] = F

- Count remaining 'true' values for 2 <= i < 10:
  * Indices with 'true': 2, 3, 5, 7 -> count = 4

Returns 4.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Optimized Sieve of Eratosthenes
class Solution {
public:
    int countPrimes(int n) {
        if (n <= 2) return 0;
        
        vector<bool> isPrime(n, true);
        isPrime[0] = false;
        isPrime[1] = false;
        
        for (long long i = 2; i * i < n; i++) {
            if (isPrime[i]) {
                for (long long j = i * i; j < n; j += i) {
                    isPrime[j] = false;
                }
            }
        }
        
        int count = 0;
        for (int i = 2; i < n; i++) {
            if (isPrime[i]) count++;
        }
        
        return count;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n log(log n))
- Explanation: The sum of reciprocals of prime numbers up to $n$ yields $O(n \log(\log n))$ complexity. Starting inner loops at $i \cdot i$ further minimizes unnecessary writes.

Space Complexity: O(n)
- Explanation: Allocates a boolean vector of size $n$. In C++, `std::vector<bool>` uses bit-packing optimization to consume approximately $n / 8$ bytes.
