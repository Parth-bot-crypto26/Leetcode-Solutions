===================================================================
LEETCODE 1967: NUMBER OF STRINGS THAT APPEAR AS SUBSTRINGS IN WORD
===================================================================

[PROBLEM DESCRIPTION]
Given an array of strings 'patterns' and a string 'word', return the number of strings in 'patterns' that exist as a substring in 'word'.
A substring is a contiguous sequence of characters within a string.

Constraints:
- 1 <= patterns.length <= 100
- 1 <= patterns[i].length <= 100
- 1 <= word.length <= 100
- 'patterns[i]' and 'word' consist of lowercase English letters.

-------------------------------------------------------------------
[METHODOLOGY: SUBSTRING MATCHING USING STD::STRING::FIND]
-------------------------------------------------------------------

1. LINEAR PATTERN SCAN:
   - Iterate through each string `pattern` in the `patterns` array.
   - Use `word.find(pattern)` to check whether `pattern` is present inside `word`.
   - `word.find(pattern)` returns the starting index of the first match if found, or `string::npos` if `pattern` is not a substring of `word`.

2. COUNTING MATCHES:
   - Incremental counter `count` tracks every pattern where `word.find(pattern) != string::npos`.
   - Given the small constraints ($N \le 100$, length $\le 100$), standard string search per pattern executes efficiently well within time limits.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: patterns = ["a", "abc", "bc", "d"], word = "abc"

- Pattern "a":
  * word.find("a") -> Index 0 != string::npos -> count = 1

- Pattern "abc":
  * word.find("abc") -> Index 0 != string::npos -> count = 2

- Pattern "bc":
  * word.find("bc") -> Index 1 != string::npos -> count = 3

- Pattern "d":
  * word.find("d") -> string::npos -> count = 3

Returns 3.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

class Solution {
public:
    int numOfStrings(vector<string>& patterns, string word) {
        int count = 0;
        for (const string& pattern : patterns) {
            if (word.find(pattern) != string::npos) {
                count++;
            }
        }
        return count;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(M * N)
- Explanation: Where 'M' is the number of patterns in `patterns` and 'N' is the length of `word`. For each pattern of length $L$, string finding takes up to $O(N \cdot L)$ time in worst-case naive search implementations. Given constraints $M, N, L \le 100$, operations total $\approx 10^6$, running instantaneously.

Space Complexity: O(1) Auxiliary Space
- Explanation: The search uses constant auxiliary space. Passing strings by const reference avoids unnecessary memory allocations.
