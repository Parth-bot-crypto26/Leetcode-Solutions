===================================================================
LEETCODE 74: SEARCH A 2D MATRIX
===================================================================

[PROBLEM DESCRIPTION]
Given an 'm x n' integer matrix 'matrix' where:
1. Each row is sorted in non-decreasing order.
2. The first integer of each row is greater than the last integer of the previous row.

Given an integer 'target', return 'true' if 'target' is in 'matrix' or 'false' otherwise.
Must achieve O(log(m * n)) time complexity.

Constraints:
- m == matrix.length
- n == matrix[i].length
- 1 <= m, n <= 100
- -10^4 <= matrix[i][j], target <= 10^4

-------------------------------------------------------------------
[METHODOLOGY: BINARY SEARCH ON VIRTUAL 1D ARRAY (O(LOG(M * N)) TIME, O(1) SPACE)]
-------------------------------------------------------------------

Your two-pass binary search approach (binary searching rows first, then elements) is functionally correct and runs in O(log m + log n) = O(log(m * n)) time.

An even cleaner implementation treats the entire $m \times n$ matrix as a single 1D sorted array of length $m \times n$:

1. INDEX MAPPING:
   - Index `mid` in a 1D array corresponds to matrix position:
     * `row = mid / n`
     * `col = mid % n`

2. SINGLE BINARY SEARCH:
   - Range: `low = 0`, `high = (m * n) - 1`.
   - Calculate `mid = low + (high - low) / 2`.
   - Map `mid` to `matrix[mid / n][mid % n]`:
     * If `matrix[row][col] == target`, return `true`.
     * If `matrix[row][col] < target`, move `low = mid + 1`.
     * If `matrix[row][col] > target`, move `high = mid - 1`.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: matrix = [[1, 3, 5, 7], [10, 11, 16, 20], [23, 30, 34, 60]], target = 3
m = 3, n = 4 | Total elements = 12

- Initial State: low = 0, high = 11

- Iteration 1:
  * mid = 0 + (11 - 0) / 2 = 5
  * row = 5 / 4 = 1, col = 5 % 4 = 1 -> matrix[1][1] = 11
  * 3 < 11 -> high = mid - 1 = 4

- Iteration 2:
  * mid = 0 + (4 - 0) / 2 = 2
  * row = 2 / 4 = 0, col = 2 % 4 = 2 -> matrix[0][2] = 5
  * 3 < 5 -> high = mid - 1 = 1

- Iteration 3:
  * mid = 0 + (1 - 0) / 2 = 0
  * row = 0 / 4 = 0, col = 0 % 4 = 0 -> matrix[0][0] = 1
  * 3 > 1 -> low = mid + 1 = 1

- Iteration 4:
  * mid = 1 + (1 - 1) / 2 = 1
  * row = 1 / 4 = 0, col = 1 % 4 = 1 -> matrix[0][1] = 3
  * 3 == 3 -> Found!

Returns true.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Approach 1: Single Pass Binary Search (Flattens 2D to 1D virtually)
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();
        
        int low = 0, high = m * n - 1;
        
        while (low <= high) {
            int mid = low + (high - low) / 2;
            int val = matrix[mid / n][mid % n];
            
            if (val == target) {
                return true;
            } else if (val < target) {
                low = mid + 1;
            } else {
                high = mid - 1;
            }
        }
        
        return false;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(log(m * n))
- Explanation: Performs standard binary search over a virtual range of $m \times n$ elements.

Space Complexity: O(1)
- Explanation: Operates strictly in-place using variable arithmetic without copying matrix data.
