[PROBLEM DESCRIPTION]
Write an efficient algorithm that searches for a value 'target' in an 'm x n' integer matrix 'matrix'.
This matrix has the following properties:
1. Integers in each row are sorted in ascending order from left to right.
2. Integers in each column are sorted in ascending order from top to bottom.

Constraints:
- m == matrix.length
- n == matrix[i].length
- 1 <= n, m <= 300
- -10^9 <= matrix[i][j], target <= 10^9

-------------------------------------------------------------------
[METHODOLOGY: STAIRCASE SEARCH / TOP-RIGHT POINTER (O(M + N) TIME, O(1) SPACE)]
-------------------------------------------------------------------

Your C++ implementation is optimal!

1. TOP-RIGHT CORNER ELIMINATION:
   - Start at `row = 0` and `col = n - 1` (top-right corner).
   - At position `matrix[row][col]`:
     * If `matrix[row][col] == target`, target is found; return `true`.
     * If `target < matrix[row][col]`, the target cannot exist in the current column (since all elements below are even larger). Eliminate this column by moving left: `col--`.
     * If `target > matrix[row][col]`, the target cannot exist in the current row (since all elements to the left are even smaller). Eliminate this row by moving down: `row++`.

2. BOUNDARY CONDITIONS:
   - Continue while `row < m` and `col >= 0`. If pointers go out of bounds, return `false`.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: matrix = [
  [ 1,  4,  7, 11, 15],
  [ 2,  5,  8, 12, 19],
  [ 3,  6,  9, 16, 22],
  [10, 13, 14, 17, 24],
  [18, 21, 23, 26, 30]
], target = 5 | m = 5, n = 5

- Initial State: row = 0, col = 4 -> matrix[0][4] = 15

- Step 1: 5 < 15 -> col-- (col = 3)
  * matrix[0][3] = 11

- Step 2: 5 < 11 -> col-- (col = 2)
  * matrix[0][2] = 7

- Step 3: 5 < 7 -> col-- (col = 1)
  * matrix[0][1] = 4

- Step 4: 5 > 4 -> row++ (row = 1)
  * matrix[1][1] = 5

- Step 5: 5 == 5 -> Match found!

Returns true.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int m = matrix.size();
        int n = matrix[0].size();
        
        int row = 0, col = n - 1;
        while (row < m && col >= 0) {
            if (target == matrix[row][col]) {
                return true;
            } else if (target < matrix[row][col]) {
                col--;
            } else {
                row++;
            }
        }
        
        return false;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(m + n)
- Explanation: At each step, either `row` is incremented or `col` is decremented. The maximum number of steps taken to traverse from top-right to bottom-left is $m + n$.

Space Complexity: O(1)
- Explanation: Operates strictly using two pointer variables (`row` and `col`) without extra allocation.
