===================================================================
LEETCODE 2965: FIND MISSING AND REPEATED VALUES
===================================================================

[PROBLEM DESCRIPTION]
You are given a 0-indexed 2D integer matrix 'grid' of size n * n with values in the range [1, n^2].
Each integer appears exactly once except 'a' which appears twice and 'b' which is missing.
Return a 0-indexed integer array 'ans' of size 2 where 'ans[0] = a' and 'ans[1] = b'.

Constraints:
- 2 <= n == grid.length == grid[i].length <= 50
- 1 <= grid[i][j] <= n * n

-------------------------------------------------------------------
[METHODOLOGY: HASH SET & MATH SUM (O(N^2) TIME, O(N^2) SPACE)]
-------------------------------------------------------------------

Your C++ implementation is optimal!

1. REPEATED VALUE ('a') FINDING:
   - Use an `unordered_set<int>` to track numbers visited while traversing the grid.
   - If `grid[i][j]` is already present in the set, it is the repeated value `a`.

2. MISSING VALUE ('b') DERIVATION:
   - Sum of numbers from $1$ to $N = n^2$ is given by $S_{expected} = \frac{N \cdot (N + 1)}{2}$.
   - Sum of elements present in the grid is $S_{actual}$.
   - The relation between expected and actual sum with $a$ (repeated) and $b$ (missing) is:
     $S_{actual} - a + b = S_{expected} \implies b = S_{expected} + a - S_{actual}$.

3. OPTIMAL MATHEMATICAL APPROACH (O(1) AUXILIARY SPACE):
   - Alternatively, compute $S_{actual}$ and $S_{actual}^2$ (sum of squares).
   - $a - b = S_{actual} - S_{expected}$
   - $a^2 - b^2 = S_{square\_actual} - S_{square\_expected}$
   - Divide to get $a + b$, then solve the system of two linear equations without using a hash set.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: grid = [[1, 3], [2, 2]] | n = 2 -> N = 4

- Expected Sum: expSum = (4 * 5) / 2 = 10
- Set s = {}, actualSum = 0

- Traversal:
  * grid[0][0] = 1 -> actualSum = 1, insert 1 into s
  * grid[0][1] = 3 -> actualSum = 4, insert 3 into s
  * grid[1][0] = 2 -> actualSum = 6, insert 2 into s
  * grid[1][1] = 2 -> 2 is already in s!
    - Repeated value a = 2
    - actualSum = 8

- Compute Missing Value:
  * b = expSum + a - actualSum = 10 + 2 - 8 = 4

Returns [2, 4].

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Approach 1: Submitted Code (Hash Set + Sum Difference)
class Solution {
public:
    vector<int> findMissingAndRepeatedValues(vector<vector<int>>& grid) {
        vector<int> ans;
        unordered_set<int> s;
        int n = grid.size();
        int a = -1, b = -1;
        long long expSum = 0, actualSum = 0;
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                actualSum += grid[i][j];
                if (s.find(grid[i][j]) != s.end()) {
                    a = grid[i][j];
                    ans.push_back(a);
                }
                s.insert(grid[i][j]);
            }
        }
        
        long long N = (long long)n * n;
        expSum = N * (N + 1) / 2;
        b = expSum + a - actualSum;
        ans.push_back(b);
        
        return ans;
    }
};

// Approach 2: Optimal O(1) Auxiliary Space Solution (Math Equations)
class SolutionMath {
public:
    vector<int> findMissingAndRepeatedValues(vector<vector<int>>& grid) {
        long long n = grid.size();
        long long N = n * n;
        
        long long sum_exp = N * (N + 1) / 2;
        long long sq_exp = N * (N + 1) * (2 * N + 1) / 6;
        
        long long sum_act = 0, sq_act = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                long long val = grid[i][j];
                sum_act += val;
                sq_act += val * val;
            }
        }
        
        long long diff_sum = sum_act - sum_exp;  // a - b
        long long diff_sq = sq_act - sq_exp;    // a^2 - b^2 = (a - b)(a + b)
        
        long long sum_ab = diff_sq / diff_sum;  // a + b
        
        int a = (diff_sum + sum_ab) / 2;
        int b = sum_ab - a;
        
        return {a, b};
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Submitted Code (Hash Set):
- Time Complexity: O(n^2) — Iterates through all $n \times n$ grid elements once.
- Space Complexity: O(n^2) — Hash set stores up to $n^2$ elements.

Mathematical Approach:
- Time Complexity: O(n^2) — Single pass over the matrix.
- Space Complexity: O(1) Auxiliary Space — Uses only scalar variables.
