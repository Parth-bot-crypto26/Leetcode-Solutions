===================================================================
LEETCODE 560: SUBARRAY SUM EQUALS K
===================================================================

[PROBLEM DESCRIPTION]
Given an array of integers 'nums' and an integer 'k', return the total number of subarrays whose sum equals to 'k'.
A subarray is a contiguous non-empty sequence of elements within an array.

Constraints:
- 1 <= nums.length <= 2 * 10^4
- -1000 <= nums[i] <= 1000
- -10^7 <= k <= 10^7

-------------------------------------------------------------------
[METHODOLOGY: PREFIX SUM + HASH MAP (O(N) TIME, O(N) SPACE)]
-------------------------------------------------------------------

Your C++ implementation is functionally correct! Here is how it can be simplified and optimized:

1. CORE MATHEMATICAL RELATION:
   - Let $P[j]$ be the running prefix sum up to index $j$.
   - A subarray from index $i$ to $j$ ($i \le j$) has sum $k$ if and only if:
     $P[j] - P[i - 1] = k \implies P[i - 1] = P[j] - k$.

2. OPTIMIZING WITH BASE FREQUENCY m[0] = 1:
   - Instead of using a separate `if(prefixSum[j] == k) count++` check, we can initialize `m[0] = 1`.
   - This base case handles subarrays starting at index 0 (where $P[j] - k = 0$).

3. SINGLE-PASS CONSTANT SPACE PRESERVATION:
   - We don't need a separate `prefixSum` vector array.
   - Maintain a scalar running sum `currSum` and update the map directly in a single pass.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [1, 1, 1], k = 2

- Initialize: currSum = 0, count = 0, m = {0: 1}

- Iteration 0 (val = 1):
  * currSum = 1
  * Needed prefix sum: currSum - k = 1 - 2 = -1
  * m.find(-1) not present -> count = 0
  * Insert currSum: m[1] = 1

- Iteration 1 (val = 1):
  * currSum = 2
  * Needed prefix sum: currSum - k = 2 - 2 = 0
  * m[0] = 1 -> count += 1 (count = 1) [Subarray: nums[0..1]]
  * Insert currSum: m[2] = 1

- Iteration 2 (val = 1):
  * currSum = 3
  * Needed prefix sum: currSum - k = 3 - 2 = 1
  * m[1] = 1 -> count += 1 (count = 2) [Subarray: nums[1..2]]
  * Insert currSum: m[3] = 1

Returns 2.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Optimized Single-Pass Implementation
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> m;
        m[0] = 1; // Base case for subarrays starting from index 0
        
        int currSum = 0;
        int count = 0;
        
        for (int num : nums) {
            currSum += num;
            int target = currSum - k;
            
            if (m.find(target) != m.end()) {
                count += m[target];
            }
            
            m[currSum]++;
        }
        
        return count;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n)
- Explanation: Single pass through array `nums` of length `n`. Hash map lookups and insertions operate in $O(1)$ average time.

Space Complexity: O(n) Auxiliary Space
- Explanation: In the worst case, all prefix sums are distinct, storing up to `n + 1` entries in the hash map.
