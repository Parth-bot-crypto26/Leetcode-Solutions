===================================================================
LEETCODE 509: FIBONACCI NUMBER
===================================================================

[PROBLEM DESCRIPTION]
The Fibonacci numbers, commonly denoted F(n) form a sequence, called the Fibonacci sequence, such that each number is the sum of the two preceding ones, starting from 0 and 1:
F(0) = 0, F(1) = 1
F(n) = F(n - 1) + F(n - 2), for n > 1.

Given n, calculate F(n).

Constraints:
- 0 <= n <= 30

-------------------------------------------------------------------
[METHODOLOGY: ITERATIVE BOTTOM-UP / DYNAMIC PROGRAMMING (O(N) TIME, O(1) SPACE)]
-------------------------------------------------------------------

Your recursive implementation is mathematically correct, but it suffers from exponential time complexity O(2^n) due to redundant subproblems.

1. RECURSIVE DRAWBACK:
   - Computing `fib(5)` calculates `fib(3)` twice, `fib(2)` three times, etc.
   - For `n = 30`, recursion makes over 2.6 million function calls!

2. OPTIMAL ITERATIVE APPROACH (SPACE OPTIMIZED DP):
   - Handle base cases: If `n <= 1`, return `n`.
   - Maintain two variables, `prev2` (for F(i-2)) and `prev1` (for F(i-1)), initialized to `0` and `1`.
   - Loop `i` from `2` to `n`:
     * Compute `curr = prev1 + prev2`.
     * Shift variables: `prev2 = prev1`, `prev1 = curr`.
   - Return `prev1`.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 4

- Base check: n > 1
- Initialize: prev2 = 0, prev1 = 1

- i = 2:
  * curr = prev1 + prev2 = 1 + 0 = 1
  * prev2 = 1, prev1 = 1
- i = 3:
  * curr = prev1 + prev2 = 1 + 1 = 2
  * prev2 = 1, prev1 = 2
- i = 4:
  * curr = prev1 + prev2 = 2 + 1 = 3
  * prev2 = 2, prev1 = 3

Returns 3.

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Optimal Iterative Approach (O(N) Time, O(1) Space)
class Solution {
public:
    int fib(int n) {
        if (n <= 1) return n;
        
        int prev2 = 0;
        int prev1 = 1;
        
        for (int i = 2; i <= n; i++) {
            int curr = prev1 + prev2;
            prev2 = prev1;
            prev1 = curr;
        }
        
        return prev1;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n)
- Explanation: Iterates linearly from 2 to `n`, performing constant-time scalar operations at each step.

Space Complexity: O(1) Auxiliary Space
- Explanation: Uses only two integer variables (`prev1`, `prev2`) to track preceding state without dynamic memory allocation or recursive call stacks.
