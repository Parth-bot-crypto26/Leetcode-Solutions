===================================================================
LEETCODE 3532: PATH EXISTENCE QUERIES IN A GRAPH I
===================================================================

[PROBLEM DESCRIPTION]
You are given an integer n representing the number of nodes in a graph, labeled from 0 to n - 1.
You are given a sorted integer array 'nums' of length n, and an integer 'maxDiff'.
An undirected edge exists between nodes i and j if |nums[i] - nums[j]| <= maxDiff.
You are given a 2D integer array queries. For each queries[i] = [ui, vi], determine whether there exists a path between nodes ui and vi.
Return a boolean array answer where answer[i] is true if a path exists between ui and vi.

Constraints:
- 1 <= n == nums.length <= 10^5
- 0 <= nums[i] <= 10^5
- nums is sorted in non-decreasing order.
- 0 <= maxDiff <= 10^5
- 1 <= queries.length <= 10^5
- queries[i] == [ui, vi]
- 0 <= ui, vi < n

-------------------------------------------------------------------
[METHODOLOGY: ADJACENT STEP CONNECTED COMPONENTS (O(N + Q) TIME, O(N) SPACE)]
-------------------------------------------------------------------

Your C++ implementation is optimal!

1. SORTED ARRAY PROPERTY & CONNECTIVITY:
   - Because `nums` is sorted in non-decreasing order (`nums[0] <= nums[1] <= ... <= nums[n-1]`), two non-adjacent nodes $i$ and $j$ ($i < j$) are connected if and only if all adjacent pairs between them satisfy `nums[k] - nums[k - 1] <= maxDiff` for all $i < k \le j$.
   - If even a single adjacent gap `nums[k] - nums[k - 1] > maxDiff`, the graph breaks into disconnected components at that split point.

2. COMPONENT ID ASSIGNMENT:
   - Assign a component ID `current_id` to node 0.
   - Iterate from index 1 to `n - 1`. If `nums[i] - nums[i - 1] > maxDiff`, increment `current_id`.
   - Assign `component[i] = current_id`.

3. CONSTANT-TIME QUERY ANSWERING:
   - For each query `[ui, vi]`, two nodes belong to the same connected component if and only if `component[ui] == component[vi]`.
   - Answers each query in $O(1)$ time.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 4, nums = [2, 5, 6, 8], maxDiff = 2, queries = [[0,1], [0,2], [1,3], [2,3]]

- Component ID Precomputation:
  * i = 0: component[0] = 0
  * i = 1: nums[1] - nums[0] = 5 - 2 = 3 > 2 -> current_id = 1 -> component[1] = 1
  * i = 2: nums[2] - nums[1] = 6 - 5 = 1 <= 2 -> component[2] = 1
  * i = 3: nums[3] - nums[2] = 8 - 6 = 2 <= 2 -> component[3] = 1
  
  component array = [0, 1, 1, 1]

- Query Processing:
  * [0, 1]: component[0] (0) == component[1] (1) -> false
  * [0, 2]: component[0] (0) == component[2] (1) -> false
  * [1, 3]: component[1] (1) == component[3] (1) -> true
  * [2, 3]: component[2] (1) == component[3] (1) -> true

Returns [false, false, true, true].

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

class Solution {
public:
    vector<bool> pathExistenceQueries(int n, vector<int>& nums, int maxDiff, vector<vector<int>>& queries) {
        vector<int> component(n, 0);
        int current_id = 0;
        
        for (int i = 1; i < n; ++i) {
            if (nums[i] - nums[i - 1] > maxDiff) {
                current_id++;
            }
            component[i] = current_id;
        }
        
        vector<bool> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            answer.push_back(component[query[0]] == component[query[1]]);
        }
        
        return answer;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n + q)
- Explanation: Precomputing component IDs takes $O(n)$ time by iterating through array `nums` once. Answering $q$ queries takes $O(q)$ total time ($O(1)$ per query). Total time complexity is $O(n + q)$.

Space Complexity: O(n) Auxiliary Space
- Explanation: Uses an integer array `component` of size $n$ to store component IDs for each node.
