===================================================================
LEETCODE 51: N-QUEENS
===================================================================

[PROBLEM DESCRIPTION]
The n-queens puzzle is the problem of placing n queens on an n x n chessboard such that no two queens attack each other.
Given an integer n, return all distinct solutions to the n-queens puzzle in any order.
Each solution contains a distinct board configuration of the n-queens' placement, where 'Q' and '.' indicate a queen and an empty space, respectively.

Constraints:
- 1 <= n <= 9

-------------------------------------------------------------------
[METHODOLOGY: BACKTRACKING WITH OPTIMIZED LOOKUP (O(N!) TIME, O(N) SPACE)]
-------------------------------------------------------------------

Your C++ implementation is correct and works well! Here is how we can optimize safety checks:

1. RECURSIVE BACKTRACKING:
   - Place queens row by row from `row = 0` to `n - 1`.
   - Placing one queen per row guarantees no two queens share a row, eliminating the horizontal check completely.

2. CONSTANT-TIME SAFETY LOOKUPS (O(1) CHECK):
   Instead of iterating through board directions in $O(N)$ time with `isSafe`:
   - Column check: Use a boolean array `cols[col]` to track occupied columns.
   - Main Diagonal (Top-Left to Bottom-Right): Cells on the same main diagonal share the same value for `(row - col + n - 1)`. Use array `diag1`.
   - Anti-Diagonal (Top-Right to Bottom-Left): Cells on the same anti-diagonal share the same value for `(row + col)`. Use array `diag2`.

3. BASE CASE:
   - When `row == n`, a valid configuration is completed. Append a copy of `board` to `ans`.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 4

- Initialize board with '.' of size 4x4.
- Recurse row = 0:
  * Try col = 0: Place Q at (0,0). Update cols[0], diag1[3], diag2[0] = true.
    - Recurse row = 1:
      * col = 0 (Attacked), col = 1 (Attacked by diag1)
      * Try col = 2: Place Q at (1,2). Update cols[2], diag1[0], diag2[3] = true.
        - Recurse row = 2:
          * All cols 0..3 attacked -> Backtrack.
  * Try col = 1: Place Q at (0,1).
    - Recurse row = 1:
      * Try col = 3: Place Q at (1,3).
        - Recurse row = 2:
          * Try col = 0: Place Q at (2,0).
            - Recurse row = 3:
              * Try col = 2: Place Q at (3,2).
                - Recurse row = 4: Base case reached -> Found solution 1: [".Q..", "...Q", "Q...", "..Q."]

-------------------------------------------------------------------
[C++ CODE IMPLEMENTATION]
-------------------------------------------------------------------

// Optimized O(1) Check Implementation
class Solution {
public:
    void nQueens(int row, int n, vector<string>& board, vector<vector<string>>& ans,
                 vector<bool>& cols, vector<bool>& diag1, vector<bool>& diag2) {
        if (row == n) {
            ans.push_back(board);
            return;
        }

        for (int col = 0; col < n; ++col) {
            int d1 = row - col + n - 1;
            int d2 = row + col;

            if (!cols[col] && !diag1[d1] && !diag2[d2]) {
                // Place Queen
                board[row][col] = 'Q';
                cols[col] = diag1[d1] = diag2[d2] = true;

                nQueens(row + 1, n, board, ans, cols, diag1, diag2);

                // Backtrack
                board[row][col] = '.';
                cols[col] = diag1[d1] = diag2[d2] = false;
            }
        }
    }

    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> ans;
        vector<string> board(n, string(n, '.'));
        vector<bool> cols(n, false);
        vector<bool> diag1(2 * n - 1, false);
        vector<bool> diag2(2 * n - 1, false);

        nQueens(0, n, board, ans, cols, diag1, diag2);
        return ans;
    }
};

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(N!)
- Explanation: In row 0 we have $N$ options, in row 1 at most $N-2$ options, in row 2 at most $N-4$ options, leading to $O(N!)$ upper bound complexity.

Space Complexity: O(N) Auxiliary Space
- Explanation: Recursion call stack reaches maximum depth of $N$. Lookup boolean arrays (`cols`, `diag1`, `diag2`) take $O(N)$ auxiliary memory.
