LEETCODE 1141: USER ACTIVITY FOR THE PAST 30 DAYS I
===================================================================

[PROBLEM DESCRIPTION]
Write a solution to find the daily active user count for a period of 30 days ending 2019-07-27 inclusively.
A user was active on a day if they performed at least one activity on that day.

Constraints & Notes:
- Activity table contains user_id, session_id, activity_date, activity_type.
- The 30-day window ending on 2019-07-27 starts on 2019-06-28 (inclusive: 2019-07-27 minus 29 days = 30 total days).
- Each active user on a given day should be counted once using `COUNT(DISTINCT user_id)`.
- Exclude days with 0 active users.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your SQL implementation is 100% optimal and correct!

1. DATE RANGE CALCULATION:
   - 30 days ending on `2019-07-27` inclusive means the date interval is `['2019-06-28', '2019-07-27']`.
   - Your condition `WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'` accurately isolates this exact 30-day window.

2. COUNT DISTINCT USERS:
   - Since a user can log multiple activity types (e.g., 'open_session', 'scroll_down') on the same day, counting total rows would count a single user multiple times.
   - `COUNT(DISTINCT user_id)` ensures each user is counted at most once per day.

3. DYNAMIC DATE ALTERNATIVE:
   - Instead of hardcoding `'2019-06-28'`, you can also express the start date dynamically in MySQL as `DATEDIFF('2019-07-27', activity_date) < 30 AND activity_date <= '2019-07-27'`.
   - However, explicit date strings allow database engines to efficiently utilize indexes on `activity_date`.

[SQL & PANDAS IMPLEMENTATIONS]
-------------------------------------------------------------------

-- SQL Solution (Your Code - Optimal & Index-Friendly)
SELECT 
    activity_date AS day,
    COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'
GROUP BY activity_date;


# Equivalent Pandas Solution (for LeetCode Pandas track)
import pandas as pd

def user_activity(activity: pd.DataFrame) -> pd.DataFrame:
    # Filter for dates within range
    mask = (activity['activity_date'] >= '2019-06-28') & (activity['activity_date'] <= '2019-07-27')
    filtered = activity[mask]
    
    # Group by date and count distinct user_id
    result = filtered.groupby('activity_date')['user_id'].nunique().reset_index()
    
    # Rename columns to match expected output format
    result.columns = ['day', 'active_users']
    return result
