===================================================================
LEETCODE 141: LINKED LIST CYCLE
===================================================================

[PROBLEM DESCRIPTION]
Given `head`, the head of a linked list, determine if the linked list 
has a cycle in it.

A cycle exists if some node in the list can be reached again by continuously 
following the `next` pointer.

Return `true` if there is a cycle in the linked list. Otherwise, return `false`.

Constraints & Notes:
- The number of nodes in the list is in the range [0, 10^4].
- `-10^5 <= Node.val <= 10^5`
- `pos` is -1 or a valid index in the linked list (internal parameter, not passed).
- Follow-up constraint: Solve in O(1) constant auxiliary memory.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation is 100% optimal and correct!

1. FLOYD'S TORTOISE AND HARE ALGORITHM:
   - Maintains two pointers: `slow` (moves 1 step at a time) and `fast` (moves 2 steps at a time).
   - If a cycle exists, the distance between `fast` and `slow` decreases by 1 in each step once both are inside the cycle, guaranteeing that `fast` will eventually catch up and meet `slow`.

2. BOUNDARY & NULL CHECKS:
   - `fast != NULL && fast->next != NULL` safely handles empty lists (`head == NULL`), single-node lists without cycles, and reaching the end of non-cyclic lists without triggering a segmentation fault.

3. MEMORY OPTIMALITY:
   - Operates in $O(1)$ extra memory since only two pointer variables are used, satisfying the follow-up requirement.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: head = [3, 2, 0, -4], pos = 1
List layout: 3 -> 2 -> 0 -> -4 -> (connects back to 2)

Initial State:
- slow = 3
- fast = 3

Iteration 1:
- slow moves to 2
- fast moves to 0
- slow != fast (2 != 0)

Iteration 2:
- slow moves to 0
- fast moves to 2 (from 0 -> -4 -> 2)
- slow != fast (0 != 2)

Iteration 3:
- slow moves to -4
- fast moves to -4 (from 2 -> 0 -> -4)
- slow == fast (-4 == -4) -> Return true!

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal O(1) Space)
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;
        
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            
            if (slow == fast) {
                return true;
            }
        }
        
        return false;
    }
};


# Equivalent Python Solution
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow = head
        fast = head
        
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            
            if slow == fast:
                return True
                
        return False

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N)
  - Non-cyclic list: Stops in N / 2 steps when fast reaches the end.
  - Cyclic list: Fast enters the cycle first. If cycle length is C, fast catches up to slow in at most C steps. Total time is linear with respect to node count N.
  
- Space Complexity: O(1) Auxiliary Space
  - Only two pointers (`slow` and `fast`) are stored in memory.
