===================================================================
LEETCODE 3536: MAXIMUM PRODUCT OF TWO DIGITS
===================================================================

[PROBLEM DESCRIPTION]
You are given a positive integer `n`.
Return the maximum product of any two digits in `n`.

Note: You may use the same digit twice if it appears more than once in `n`.

Constraints & Notes:
- `10 <= n <= 10^9` (Guarantees `n` has at least 2 digits).
- Since all digits are non-negative ($0 \le \text{digit} \le 9$), the maximum product of any two digits will always be formed by multiplying the **largest digit** and the **second largest digit** present in `n`.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation is 100% optimal and correct!

1. TRACKING TOP TWO MAXIMA IN A SINGLE PASS:
   - By extracting digits using modulo (`n % 10`) and division (`n /= 10`), you extract every digit in $O(\log_{10} n)$ time without string conversion overhead.
   - Maintaining `max1` (largest digit seen so far) and `max2` (second largest digit seen so far) guarantees finding the top two digits in a single pass.

2. CONDITIONAL UPDATE LOGIC:
   - `if (digit > max1)`: Correctly demotes the former largest digit `max1` to `max2` and updates `max1 = digit`.
   - `else if (digit > max2)`: Handles duplicate top digits (e.g., `n = 55`) or values smaller than `max1` but strictly greater than `max2`.

3. MEMORY OPTIMALITY:
   - Performs extraction in-place using primitive variables, keeping space complexity at $O(1)$.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 124

Initial State:
- max1 = 0, max2 = 0

Iteration 1:
- digit = 124 % 10 = 4
- digit (4) > max1 (0) -> max2 = 0, max1 = 4
- n = 12

Iteration 2:
- digit = 12 % 10 = 2
- digit (2) NOT > max1 (4)
- digit (2) > max2 (0) -> max2 = 2
- n = 1

Iteration 3:
- digit = 1 % 10 = 1
- digit (1) NOT > max1 (4)
- digit (1) NOT > max2 (2)
- n = 0 (Loop ends)

Final Calculation:
- max1 * max2 = 4 * 2 = 8 -> Return 8

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Single-Pass O(1) Space)
class Solution {
public:
    int maxProduct(int n) {
        int max1 = 0, max2 = 0;
        
        while (n > 0) {
            int digit = n % 10;
            if (digit > max1) {
                max2 = max1;
                max1 = digit;
            } else if (digit > max2) {
                max2 = digit;
            }
            n /= 10;
        }
        
        return max1 * max2;
    }
};


# Equivalent Python Solution
class Solution:
    def maxProduct(self, n: int) -> int:
        max1, max2 = 0, 0
        
        while n > 0:
            digit = n % 10
            if digit > max1:
                max2 = max1
                max1 = digit
            elif digit > max2:
                max2 = digit
            n //= 10
            
        return max1 * max2

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(log10(N))
  - The number of iterations is proportional to the number of digits in $N$. Since $N \le 10^9$, there are at most 10 iterations (constant upper bound).

- Space Complexity: O(1) Auxiliary Space
  - Only integer variables (`max1`, `max2`, `digit`) are used.
