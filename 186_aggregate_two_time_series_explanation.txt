===================================================================
LEETCODE 4001: AGGREGATE TWO TIME SERIES
===================================================================

[PROBLEM DESCRIPTION]
You are given two 2D integer arrays `series1` and `series2` representing 
time series sorted in strictly increasing order of timestamps: `[timestamp, value]`.

Rules for missing timestamps:
- For any timestamp `t` not explicitly present in a series, its effective value 
  is taken from the **next available timestamp** in that same series (i.e., smallest 
  timestamp $t' \ge t$). If no such future timestamp exists, its value is `0`.
- Combine the two series at every unique timestamp that appears in either series 
  by taking the sum of their effective values.

Return the result sorted by timestamp in strictly increasing order.

Constraints & Notes:
- $1 \le \text{series1.length}, \text{series2.length} \le 10^5$
- $1 \le \text{timestamp}, \text{value} \le 10^9$
- Overflow Notice: Summing values up to $10^9 + 10^9 = 2 \cdot 10^9$ fits inside a standard 32-bit signed integer (`int`), but `long long` avoids potential arithmetic cast bugs.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your two-pointer C++ implementation is 100% optimal and correct!

1. TWO-POINTER MERGE PATTERN:
   - Maintains pointer `i` for `series1` and `j` for `series2`.
   - At each step, determines the next target timestamp `t` as `min(series1[i][0], series2[j][0])`.

2. RESOLVING FUTURE VALUE LOOKUPS IN O(1):
   - Since both input series are strictly increasing, index `i` points directly to the **first timestamp $\ge t$** in `series1`.
   - Thus, `(i < n1) ? series1[i][1] : 0` retrieves the value at $t$ or the next available timestamp in $O(1)$ time without requiring binary search!
   - The same property holds for `j` in `series2`.

3. ADVANCING POINTERS:
   - If `series1[i][0] == t`, index `i` advances to prepare for the next distinct timestamp.
   - If `series2[j][0] == t`, index `j` advances similarly.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: series1 = [[1,3],[4,1]], series2 = [[2,2],[5,2]]

Initialization:
- i = 0 (n1 = 2), j = 0 (n2 = 2)

Iteration 1:
- t = min(series1[0][0], series2[0][0]) = min(1, 2) = 1
- val1 = series1[0][1] = 3 (since series1[0][0] == 1)
- val2 = series2[0][1] = 2 (since index j=0 has timestamp 2 >= 1)
- Sum = 3 + 2 = 5
- Add [1, 5] to result.
- series1[0][0] == 1 -> i becomes 1.

Iteration 2:
- t = min(series1[1][0], series2[0][0]) = min(4, 2) = 2
- val1 = series1[1][1] = 1 (since index i=1 has timestamp 4 >= 2)
- val2 = series2[0][1] = 2 (since series2[0][0] == 2)
- Sum = 1 + 2 = 3
- Add [2, 3] to result.
- series2[0][0] == 2 -> j becomes 1.

Iteration 3:
- t = min(series1[1][0], series2[1][0]) = min(4, 5) = 4
- val1 = series1[1][1] = 1 (since series1[1][0] == 4)
- val2 = series2[1][1] = 2 (since index j=1 has timestamp 5 >= 4)
- Sum = 1 + 2 = 3
- Add [4, 3] to result.
- series1[1][0] == 4 -> i becomes 2.

Iteration 4:
- t = series2[1][0] = 5
- val1 = 0 (i == n1, no future timestamp)
- val2 = series2[1][1] = 2 (series2[1][0] == 5)
- Sum = 0 + 2 = 2
- Add [5, 2] to result.
- series2[1][0] == 5 -> j becomes 2.

Output: [[1,5], [2,3], [4,3], [5,2]]

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Clean & Optimal O(N1 + N2))
#include <vector>
#include <algorithm>

class Solution {
public:
    std::vector<std::vector<int>> aggregateTimeSeries(std::vector<std::vector<int>>& series1, std::vector<std::vector<int>>& series2) {
        std::vector<std::vector<int>> ans;
        int i = 0, j = 0;
        int n1 = series1.size(), n2 = series2.size();

        while (i < n1 || j < n2) {
            int t;
            if (i < n1 && j < n2) {
                t = std::min(series1[i][0], series2[j][0]);
            } else if (i < n1) {
                t = series1[i][0];
            } else {
                t = series2[j][0];
            }

            int val1 = (i < n1) ? series1[i][1] : 0;
            int val2 = (j < n2) ? series2[j][1] : 0;

            ans.push_back({t, val1 + val2});

            if (i < n1 && series1[i][0] == t) i++;
            if (j < n2 && series2[j][0] == t) j++;
        }

        return ans;
    }
};


# Equivalent Python Solution
class Solution:
    def aggregateTimeSeries(self, series1: list[list[int]], series2: list[list[int]]) -> list[list[int]]:
        ans = []
        i, j = 0, 0
        n1, n2 = len(series1), len(series2)
        
        while i < n1 or j < n2:
            if i < n1 and j < n2:
                t = min(series1[i][0], series2[j][0])
            elif i < n1:
                t = series1[i][0]
            else:
                t = series2[j][0]
                
            val1 = series1[i][1] if i < n1 else 0
            val2 = series2[j][1] if j < n2 else 0
            
            ans.append([t, val1 + val2])
            
            if i < n1 and series1[i][0] == t:
                i += 1
            if j < n2 and series2[j][0] == t:
                j += 1
                
        return ans

[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N1 + N2)
  - Each step processes at least one timestamp from `series1` or `series2` and increments `i` or `j`.
  - The loop terminates in at most $N_1 + N_2$ iterations.

- Space Complexity: O(1) Auxiliary Space
  - Excludes the memory allocated for the output result vector `ans`.
