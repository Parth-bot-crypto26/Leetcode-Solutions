===================================================================
LEETCODE 4002: COUNT VALID SEQUENCES
===================================================================

[PROBLEM DESCRIPTION]
You are given two positive integers `n` and `k`.
Find the number of sequences of `k` positive integers such that:
1. The sum of all integers in the sequence is equal to `n`.
2. The product of all integers in the sequence is **even**.

Return the total number of valid sequences modulo 10^9 + 7.

Constraints & Notes:
- 1 <= n <= 5 * 10^5
- 1 <= k <= n
- Modulo = 10^9 + 7

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your mathematical approach using the Complementary Counting Principle & Stars and Bars is 100% optimal and correct!

1. COMPLEMENTARY COUNTING PRINCIPLE:
   $$\text{Valid Sequences} = \text{Total Sequences with Sum } n - \text{Sequences with ALL ODD Numbers}$$
   - A product is even if at least one number is even.
   - The complement is that **all $k$ numbers are odd**.

2. TOTAL SEQUENCES (STARS AND BARS):
   - Number of positive integer solutions to $x_1 + x_2 + \dots + x_k = n$ (where $x_i \ge 1$):
     $$\text{Total} = \binom{n-1}{k-1}$$

3. SEQUENCES WITH ALL ODD NUMBERS:
   - Let each $x_i = 2y_i + 1$ where $y_i \ge 0$.
   - Substituting into the sum equation:
     $$\sum_{i=1}^{k} (2y_i + 1) = n \implies 2 \sum_{i=1}^{k} y_i + k = n \implies \sum_{i=1}^{k} y_i = \frac{n - k}{2}$$
   - **Condition for existence:** $(n - k)$ must be even. If $(n - k)$ is odd, it is impossible for all $k$ positive numbers to be odd, so $\text{All\_Odd} = 0$.
   - **Solving for non-negative $y_i$:** Letting $m = \frac{n - k}{2}$, the number of non-negative integer solutions is:
     $$\text{All\_Odd} = \binom{m + k - 1}{k - 1}$$

4. COMBINATORIAL FACTORIAL PRECOMPUTATION OPTIMIZATION:
   - While your $O(k)$ dynamic calculation of $\binom{N}{R}$ is correct, precomputing factorials and inverse factorials up to $N = 5 \cdot 10^5$ reduces `nCr` execution time to $O(1)$ per query.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 5, k = 3

1. Total Sequences:
   - Total = C(5 - 1, 3 - 1) = C(4, 2) = 6.

2. All-Odd Sequences:
   - Check (n - k) = 5 - 3 = 2 (Even).
   - m = (5 - 3) / 2 = 1.
   - All_Odd = C(m + k - 1, k - 1) = C(1 + 3 - 1, 3 - 1) = C(3, 2) = 3.

3. Result:
   - Valid = Total - All_Odd = 6 - 3 = 3. -> Return 3.

[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (O(1) nCr via Precomputed Factorials)
#include <vector>

class Solution {
    long long MOD = 1e9 + 7;
    std::vector<long long> fact, invFact;

    long long power(long long base, long long exp) {
        long long res = 1;
        base %= MOD;
        while (exp > 0) {
            if (exp % 2 == 1) res = (res * base) % MOD;
            base = (base * base) % MOD;
            exp /= 2;
        }
        return res;
    }

    long long modInverse(long long n) {
        return power(n, MOD - 2);
    }

    void precompute(int maxN) {
        fact.resize(maxN + 1, 1);
        invFact.resize(maxN + 1, 1);
        for (int i = 1; i <= maxN; i++) {
            fact[i] = (fact[i - 1] * i) % MOD;
        }
        invFact[maxN] = modInverse(fact[maxN]);
        for (int i = maxN - 1; i >= 1; i--) {
            invFact[i] = (invFact[i + 1] * (i + 1)) % MOD;
        }
    }

    long long nCr(int n, int r) {
        if (r < 0 || r > n) return 0;
        return fact[n] * invFact[r] % MOD * invFact[n - r] % MOD;
    }

public:
    int countValidSequences(int n, int k) {
        precompute(n);

        long long total = nCr(n - 1, k - 1);
        long long all_odd = 0;

        if ((n - k) % 2 == 0) {
            int m = (n - k) / 2;
            all_odd = nCr(m + k - 1, k - 1);
        }

        return (total - all_odd + MOD) % MOD;
    }
};


# Equivalent Python Solution
class Solution:
    def countValidSequences(self, n: int, k: int) -> int:
        MOD = 10**9 + 7
        
        # Precompute factorials up to n
        fact = [1] * (n + 1)
        invFact = [1] * (n + 1)
        
        for i in range(1, n + 1):
            fact[i] = (fact[i - 1] * i) % MOD
            
        invFact[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n - 1, 0, -1):
            invFact[i] = (invFact[i + 1] * (i + 1)) % MOD
            
        def nCr(N, R):
            if R < 0 or R > N:
                return 0
            return fact[N] * invFact[R] % MOD * invFact[N - R] % MOD
        
        total = nCr(n - 1, k - 1)
        all_odd = 0
        
        if (n - k) % 2 == 0:
            m = (n - k) // 2
            all_odd = nCr(m + k - 1, k - 1)
            
        return (total - all_odd) % MOD

[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N)
  - Precomputing factorials up to $N$ takes $O(N)$ time.
  - Computing `total` and `all_odd` using precomputed combinations takes $O(1)$ time.

- Space Complexity: O(N) Auxiliary Space
  - Uses $O(N)$ space to store `fact` and `invFact` tables.
