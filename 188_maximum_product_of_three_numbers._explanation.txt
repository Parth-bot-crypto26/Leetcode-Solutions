===================================================================
LEETCODE 628: MAXIMUM PRODUCT OF THREE NUMBERS
===================================================================

[PROBLEM DESCRIPTION]
You are given an integer array `nums`.
Find three numbers whose product is maximum and return the maximum product.

Constraints & Notes:
- 3 <= nums.length <= 10^4
- -1000 <= nums[i] <= 1000

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation is 100% logic-wise correct!

1. MATHEMETICAL CASE ANALYSIS:
   The maximum product of three numbers in an array containing both positive 
   and negative numbers can only come from two scenarios:
   - Scenario 1 (`ans1`): The product of the three largest numbers 
     (`nums[n-1] * nums[n-2] * nums[n-3]`).
   - Scenario 2 (`ans2`): The product of the two smallest numbers (which could be 
     large negative numbers) and the single largest positive number 
     (`nums[0] * nums[1] * nums[n-1]`).

2. SORTING APPROACH (YOUR CODE):
   - Sorting takes $O(N \log N)$ time and easily gives access to the top 3 largest 
     and top 2 smallest elements.

3. OPTIMAL SINGLE-PASS APPROACH:
   - Instead of sorting the whole array in $O(N \log N)$ time, we can find the 
     `max1`, `max2`, `max3` and `min1`, `min2` in a single pass in $O(N)$ time 
     and $O(1)$ space.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [-10, -10, 1, 3, 2]

Sorted Array: [-10, -10, 1, 2, 3]
- n = 5
- ans1 = nums[4] * nums[3] * nums[2] = 3 * 2 * 1 = 6
- ans2 = nums[0] * nums[1] * nums[4] = (-10) * (-10) * 3 = 300

Result: max(6, 300) = 300

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// Approach 1: Sorting (Your Code - O(N log N) Time, O(1) Space)
#include <vector>
#include <algorithm>

class Solution {
public:
    int maximumProduct(std::vector<int>& nums) {
        std::sort(nums.begin(), nums.end());
        int n = nums.size();
        int ans1 = nums[n - 1] * nums[n - 2] * nums[n - 3];
        int ans2 = nums[0] * nums[1] * nums[n - 1];
        return std::max(ans1, ans2);
    }
};


// Approach 2: Single Pass (Optimal - O(N) Time, O(1) Space)
#include <vector>
#include <algorithm>
#include <climits>

class SolutionOptimal {
public:
    int maximumProduct(std::vector<int>& nums) {
        int max1 = INT_MIN, max2 = INT_MIN, max3 = INT_MIN;
        int min1 = INT_MAX, min2 = INT_MAX;

        for (int n : nums) {
            // Track 3 largest values
            if (n > max1) {
                max3 = max2;
                max2 = max1;
                max1 = n;
            } else if (n > max2) {
                max3 = max2;
                max2 = n;
            } else if (n > max3) {
                max3 = n;
            }

            // Track 2 smallest values
            if (n < min1) {
                min2 = min1;
                min1 = n;
            } else if (n < min2) {
                min2 = n;
            }
        }

        return std::max(max1 * max2 * max3, min1 * min2 * max1);
    }
};


# Equivalent Python Solution (O(N) Time using heap or single pass)
class Solution:
    def maximumProduct(self, nums: list[int]) -> int:
        import heapq
        
        # Top 3 largest and Top 2 smallest
        largest = heapq.nlargest(3, nums)
        smallest = heapq.nsmallest(2, nums)
        
        ans1 = largest[0] * largest[1] * largest[2]
        ans2 = smallest[0] * smallest[1] * largest[0]
        
        return max(ans1, ans2)
