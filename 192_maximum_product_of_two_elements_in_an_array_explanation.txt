===================================================================
LEETCODE 1464: MAXIMUM PRODUCT OF TWO ELEMENTS IN AN ARRAY
===================================================================

[PROBLEM DESCRIPTION]
Given an array of integers `nums`, choose two distinct indices `i` and `j`.
Return the maximum value of `(nums[i] - 1) * (nums[j] - 1)`.

Constraints & Notes:
- `2 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`
- All values in `nums` are positive ($nums[i] \ge 1$), which means $(nums[i] - 1) \ge 0$.
- Consequently, maximizing $(nums[i] - 1) * (nums[j] - 1)$ is directly equivalent to finding the **two largest elements** in `nums`.

-------------------------------------------------------------------
[METHODOLOGY & SOLUTIONS]
-------------------------------------------------------------------

There are two main ways to solve this problem:

1. SINGLE PASS TO TRACK TOP TWO MAXIMA (OPTIMAL):
   - Iterate through `nums` maintaining `max1` (largest value seen so far) and `max2` (second largest value seen so far).
   - If `x > max1`: demote `max1` to `max2`, and set `max1 = x`.
   - Else if `x > max2`: set `max2 = x`.
   - Time Complexity: $O(N)$
   - Space Complexity: $O(1)$

2. SORTING APPROACH:
   - Sort `nums` in ascending order.
   - The two largest elements will be at the end (`nums[n-1]` and `nums[n-2]`).
   - Time Complexity: $O(N \log N)$
   - Space Complexity: $O(1)$ or $O(\log N)$ depending on sorting algorithm.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [3, 4, 5, 2]

Initial State:
- max1 = 0, max2 = 0

Iteration 1 (x = 3):
- x (3) > max1 (0) -> max2 = 0, max1 = 3

Iteration 2 (x = 4):
- x (4) > max1 (3) -> max2 = 3, max1 = 4

Iteration 3 (x = 5):
- x (5) > max1 (4) -> max2 = 4, max1 = 5

Iteration 4 (x = 2):
- x (2) NOT > max1 (5)
- x (2) NOT > max2 (4) -> No change

End of Loop:
- max1 = 5, max2 = 4

Result Calculation:
- (max1 - 1) * (max2 - 1) = (5 - 1) * (4 - 1) = 4 * 3 = 12

Resulting Output:
12

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// Approach 1: Single Pass Tracking Top 2 Maxima (Optimal)
#include <vector>
#include <algorithm>

class Solution {
public:
    int maxProduct(std::vector<int>& nums) {
        int max1 = 0, max2 = 0;
        
        for (int x : nums) {
            if (x > max1) {
                max2 = max1;
                max1 = x;
            } else if (x > max2) {
                max2 = x;
            }
        }
        
        return (max1 - 1) * (max2 - 1);
    }
};


// Approach 2: Sorting Approach
class SolutionSorting {
public:
    int maxProduct(std::vector<int>& nums) {
        std::sort(nums.begin(), nums.end());
        int n = nums.size();
        return (nums[n - 1] - 1) * (nums[n - 2] - 1);
    }
};


# Equivalent Python Solution (Single Pass)
class Solution:
    def maxProduct(self, nums: list[int]) -> int:
        max1, max2 = 0, 0
        
        for x in nums:
            if x > max1:
                max2 = max1
                max1 = x
            elif x > max2:
                max2 = x
                
        return (max1 - 1) * (max2 - 1)

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Single Pass Approach (Optimal):
- Time Complexity: O(N) where N is the length of nums (single loop traversal).
- Space Complexity: O(1) Auxiliary Space since only two primitive variables (`max1`, `max2`) are stored.

Sorting Approach:
- Time Complexity: O(N log N) due to std::sort.
- Space Complexity: O(1) Auxiliary Space.
