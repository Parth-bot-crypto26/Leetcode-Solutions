===================================================================
LEETCODE 178: RANK SCORES
===================================================================

[PROBLEM DESCRIPTION]
Write a solution to find the rank of the scores based on these rules:
1. Scores should be ranked from highest to lowest.
2. If there is a tie between two scores, both should have the same ranking.
3. After a tie, the next ranking number should be the **next consecutive integer value** (no holes between ranks).

Return the result table ordered by score in descending order.

Constraints & Notes:
- `Scores` table: `id` (Primary Key), `score` (Decimal with two decimal places).
- Window function requirement: `DENSE_RANK()` provides dense ranking without gaps after ties, exactly matching rule #3.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your SQL implementation is 100% optimal and correct!

1. WINDOW FUNCTION `DENSE_RANK()`:
   - `DENSE_RANK() OVER (ORDER BY score DESC)` correctly assigns identical ranks to tied scores and ensures that subsequent ranks increment by 1 without any gaps (unlike `RANK()`, which leaves gaps).

2. ORDERING:
   - `ORDER BY score DESC` at the outer query level satisfies the requirement that the final result table be ordered by score from highest to lowest.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: 
Scores Table:
+----+-------+
| id | score |
+----+-------+
| 1  | 3.50  |
| 2  | 3.65  |
| 3  | 4.00  |
| 4  | 3.85  |
| 5  | 4.00  |
| 6  | 3.65  |
+----+-------+

Processing `DENSE_RANK() OVER (ORDER BY score DESC)`:
- Sort scores descending: 4.00, 4.00, 3.85, 3.65, 3.65, 3.50
- 4.00 -> Rank 1 (Tie)
- 4.00 -> Rank 1 (Tie)
- 3.85 -> Rank 2 (Next consecutive integer)
- 3.65 -> Rank 3 (Tie)
- 3.65 -> Rank 3 (Tie)
- 3.50 -> Rank 4 (Next consecutive integer)

Output:
+-------+------+
| score | rank |
+-------+------+
| 4.00  | 1    |
| 4.00  | 1    |
| 3.85  | 2    |
| 3.65  | 3    |
| 3.65  | 3    |
| 3.50  | 4    |
+-------+------+

-------------------------------------------------------------------
[SQL & PANDAS IMPLEMENTATIONS]
-------------------------------------------------------------------

-- SQL Solution (Your Code - Optimal)
SELECT
    score,
    DENSE_RANK() OVER (ORDER BY score DESC) AS 'rank'
FROM Scores
ORDER BY score DESC;


# Equivalent Pandas Solution (for LeetCode Pandas track)
import pandas as pd

def order_scores(scores: pd.DataFrame) -> pd.DataFrame:
    # Use dense rank method
    scores['rank'] = scores['score'].rank(method='dense', ascending=False)
    
    # Sort by score in descending order and select columns
    result = scores[['score', 'rank']].sort_values(by='score', ascending=False)
    
    return result

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N log N)
  - Sorting the table rows by score to compute the window function takes $O(N \log N)$ time.

- Space Complexity: O(N) Auxiliary Space
  - Space required for the database engine to sort and assign window partition ranks for $N$ rows.
