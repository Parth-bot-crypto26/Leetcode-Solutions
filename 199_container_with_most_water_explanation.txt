===================================================================
LEETCODE 11: CONTAINER WITH MOST WATER
===================================================================

[PROBLEM DESCRIPTION]
You are given an integer array `height` of length `n`. There are `n` vertical lines 
drawn such that the two endpoints of the `i-th` line are `(i, 0)` and `(i, height[i])`.

Find two lines that together with the x-axis form a container, such that the 
container contains the most water. Return the maximum amount of water.

Constraints & Notes:
- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your two-pointer C++ implementation is 100% optimal and correct!

1. TWO-POINTER GREEDY STRATEGY:
   - Initialize `left = 0` and `right = n - 1`. The initial width is maximized.
   - At each step, compute the area: $\text{width} \times \min(\text{height}[left], \text{height}[right])$.
   - Update `maxWater` with the peak value encountered.

2. WHY THE POINTER MOVEMENT LOGIC WORKS:
   - The area is limited by the **shorter** of the two lines (`height[left]` vs `height[right]`).
   - Moving the pointer of the *taller* line inward can never increase the area because the width strictly decreases, and the height is still bounded by the same or an even shorter line. 
   - Therefore, to potentially find a taller boundary that compensates for the decreasing width, we must always increment `left` if `height[left] < height[right]`, else decrement `right`.

Iteration 2:

- w = 4 - 1 = 3
- ht = min(8, 5) = 5
- currWater = 3 * 5 = 15
- maxWater = max(4, 15) = 15
- height[left] (8) < height[right] (5) is False -> right becomes 3.

Iteration 3:
- left = 1 (val = 8), right = 3 (val = 2)
- w = 3 - 1 = 2
- ht = min(8, 2) = 2
- currWater = 2 * 2 = 4
- maxWater = max(15, 4) = 15
- height[left] (8) < height[right] (2) is False -> right becomes 2.

Iteration 4:
- left = 1 (val = 8), right = 2 (val = 6)
- w = 2 - 1 = 1
- ht = min(8, 6) = 6
- currWater = 1 * 6 = 6
- maxWater = max(15, 6) = 15
- height[left] (8) < height[right] (6) is False -> right becomes 1.
- Loop terminates (`left` no longer < `right`).

[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Two-Pointer)
#include <vector>
#include <algorithm>

class Solution {
public:
    int maxArea(std::vector<int>& height) {
        int n = height.size();
        int maxWater = 0;
        int left = 0, right = n - 1;

        while (left < right) {
            int w = right - left;
            int ht = std::min(height[left], height[right]);
            int currWater = w * ht;
            maxWater = std::max(maxWater, currWater);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxWater;
    }
};


# Equivalent Python Solution
class Solution:
    def maxArea(self, height: list[int]) -> int:
        max_water = 0
        left, right = 0, len(height) - 1
        
        while left < right:
            w = right - left
            ht = min(height[left], height[right])
            max_water = max(max_water, w * ht)
            
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
                
        return max_water

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N)
  - The two pointers `left` and `right` start at opposite ends and move toward each other, visiting each element at most once.

- Space Complexity: O(1) Auxiliary Space
  - Uses a constant amount of extra memory for pointer variables and scalar calculations.
