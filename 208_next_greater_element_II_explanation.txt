===================================================================
LEETCODE 503: NEXT GREATER ELEMENT II
===================================================================

[PROBLEM DESCRIPTION]
Given a circular integer array `nums` (where the next element of `nums[nums.length - 1]` 
is `nums[0]`), return the next greater number for every element in `nums`.

The next greater number of a number `x` is the first greater number encountered 
by searching circularly in the array. If it doesn't exist, return `-1`.

Constraints & Notes:
- `1 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation is **100% optimal, elegant, and exceptionally clever!**

1. CIRCULAR ARRAY SIMULATION ($2N$ TRAVERSAL):
   - To handle the circular nature without modifying or duplicating the array explicitly, 
     you run a loop from `2 * n - 1` down to `0`. 
   - By utilizing modulo indexing (`i % n`), the first pass (from `2 * n - 1` down to `n`) 
     acts as a pre-population phase that feeds potential future greater elements into the stack, 
     while the second pass computes the actual answers for the real array indices.

2. MONOTONIC DECREASING STACK:
   - The stack stores indices of `nums`. 
   - Any element in the stack smaller than or equal to the current element (`nums[i % n]`) 
     is popped because it can never be the next greater element.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [1, 2, 1] (n = 3)

Loop from i = 5 down to 0 (indices accessed via `i % n`):
- i = 5 (val = nums[2] = 1): stack empty -> ans[2] = -1. Push index 2.
- i = 4 (val = nums[1] = 2): stack top has index 2 (val 1 $\le 2$) -> pop index 2. Stack empty -> ans[1] = -1. Push index 1.
- i = 3 (val = nums[0] = 1): stack top has index 1 (val 2 > 1) -> ans[0] = 2. Push index 0.
- i = 2 (val = nums[2] = 1): stack top has index 0 (val 1 $\le 1$) -> pop index 0. Stack top has index 1 (val 2 > 1) -> ans[2] = 2. Push index 2.
- i = 1 (val = nums[1] = 2): stack top has index 2 (val 1 $\le 2$) -> pop index 2. Stack top has index 1 (val 2 $\le 2$) -> pop index 1. Stack empty -> ans[1] = -1. Push index 1.
- i = 0 (val = nums[0] = 1): stack top has index 1 (val 2 > 1) -> ans[0] = 2. Push index 0.

Final Answer Array: `[2, -1, 2]`

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Monotonic Stack with Modulo Indexing)
#include <vector>
#include <stack>

class Solution {
public:
    std::vector<int> nextGreaterElements(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<int> ans(n, -1);
        std::stack<int> s;
        
        for (int i = 2 * n - 1; i >= 0; i--) {
            while (!s.empty() && nums[s.top()] <= nums[i % n]) {
                s.pop();
            }
            ans[i % n] = s.empty() ? -1 : nums[s.top()];
            s.push(i % n);
        }
        
        return ans;
    }
};


# Equivalent Python Solution
class Solution:
    def nextGreaterElements(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [-1] * n
        stack = []
        
        for i in range(2 * n - 1, -1, -1):
            while stack and nums[stack[-1]] <= nums[i % n]:
                stack.pop()
            if stack:
                ans[i % n] = nums[stack[-1]]
            stack.append(i % n)
            
        return ans

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N)
  - The loop runs $2N$ times. Each element is pushed onto and popped from the stack at most twice, resulting in linear time complexity.

- Space Complexity: O(N) Auxiliary Space
  - Space required for the stack and the output array of size `N`.
