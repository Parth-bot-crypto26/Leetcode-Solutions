===================================================================
LEETCODE 4: MEDIAN OF TWO SORTED ARRAYS
===================================================================

[PROBLEM DESCRIPTION]
Given two sorted arrays `nums1` and `nums2` of size `m` and `n` respectively, 
return the median of the two sorted arrays.

The overall run time complexity should be $O(\log(m + n))$.

Constraints & Notes:
- `nums1.length == m`, `nums2.length == n`
- `0 <= m, n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your current C++ implementation combines both arrays and sorts them:

1. BRUTE-FORCE COLLECTION & SORTING:
   - You push all elements from `nums1` and `nums2` into a vector `ans` and call `sort()`.
   - Then you calculate the median depending on whether the total size `n` is odd or even.

2. COMPLEXITY CRITIQUE:
   - Time Complexity of your code: $O((m + n) \log(m + n))$ due to the sorting step. 
   - Under the problem's constraints ($m, n \le 1000$), your solution passes successfully on LeetCode because $(2000) \log_2(2000)$ is extremely small.
   - However, the problem sets a strict follow-up requirement: **$O(\log(m + n))$ time complexity**. To achieve this, we must use a **Binary Search on Partitions** algorithm.

3. OPTIMAL BINARY SEARCH PARTITION STRATEGY:
   - Instead of merging or sorting, we partition both arrays into left and right halves such that every element on the left is less than or equal to every element on the right.
   - By binary searching on the smaller array (`nums1`), we find the correct partition in $O(\log(\min(m, n)))$ time.

-------------------------------------------------------------------
[DRY RUN EXAMPLE (Optimal Binary Search Partition)]
-------------------------------------------------------------------
Input: nums1 = [1, 3], nums2 = [2]

- Ensure `nums1` is the smaller array (length $m = 2$, length $n = 1$).
- Total elements = 3. Left half size = $(2 + 1 + 1) / 2 = 2$.
- Binary search range for `nums1` partition (`partitionX`): from 0 to 2.
  - Try `partitionX = 1` (takes element `1` from `nums1`).
  - `partitionY = leftSize - partitionX = 2 - 1 = 1` (takes element `2` from `nums2`).
  - Left partition elements: `nums1[0]` (1) and `nums2[0]` (2).
  - Right partition elements: `nums1[1]` (3) (and no elements remaining in `nums2`).
  - Check boundary conditions: `maxLeftX` ($\le 1$) and `maxLeftY` ($\le 2$) are both $\le$ `minRightX` ($\ge 3$).
- Since total length is odd, the median is the maximum of the left partition elements: $\max(1, 2) = 2.0$.

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution 1: Your Sorting Approach (Passes due to small constraints)
#include <vector>
#include <algorithm>

class SolutionSorting {
public:
    double findMedianSortedArrays(std::vector<int>& nums1, std::vector<int>& nums2) {
        std::vector<double> ans;
        for (double i : nums1) ans.push_back(i);
        for (double j : nums2) ans.push_back(j);
        
        std::sort(ans.begin(), ans.end());
        int n = ans.size();
        int mid = n / 2;
        
        if (n % 2 != 0) {
            return ans[mid];
        } else {
            return (ans[mid - 1] + ans[mid]) / 2.0;
        }
    }
};


// C++ Solution 2: Optimal Binary Search Partition Approach (O(log(min(m, n))))
#include <vector>
#include <algorithm>
#include <climits>

class Solution {
public:
    double findMedianSortedArrays(std::vector<int>& nums1, std::vector<int>& nums2) {
        if (nums1.size() > nums2.size()) {
            return findMedianSortedArrays(nums2, nums1); // Ensure nums1 is the smaller array
        }
        
        int m = nums1.size();
        int n = nums2.size();
        int low = 0, high = m;
        int halfLen = (m + n + 1) / 2;
        
        while (low <= high) {
            int partitionX = low + (high - low) / 2;
            int partitionY = halfLen - partitionX;
            
            int maxLeftX = (partitionX == 0) ? INT_MIN : nums1[partitionX - 1];
            int minRightX = (partitionX == m) ? INT_MAX : nums1[partitionX];
            
            int maxLeftY = (partitionY == 0) ? INT_MIN : nums2[partitionY - 1];
            int minRightY = (partitionY == n) ? INT_MAX : nums2[partitionY];
            
            if (maxLeftX <= minRightY && maxLeftY <= minRightX) {
                // Correct partition found
                if ((m + n) % 2 == 1) {
                    return std::max(maxLeftX, maxLeftY);
                } else {
                    return (std::max(maxLeftX, maxLeftY) + std::min(minRightX, minRightY)) / 2.0;
                }
            } else if (maxLeftX > minRightY) {
                high = partitionX - 1; // Move too far right in nums1, shift left
            } else {
                low = partitionX + 1;  // Move too far left in nums1, shift right
            }
        }
        
        return 0.0;
    }
};


# Equivalent Python Solution (Optimal Binary Search Partition)
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
            
        m, n = len(nums1), len(nums2)
        low, high = 0, m
        half_len = (m + n + 1) // 2
        
        while low <= high:
            partition_x = (low + high) // 2
            partition_y = half_len - partition_x
            
            max_left_x = -float('inf') if partition_x == 0 else nums1[partition_x - 1]
            min_right_x = float('inf') if partition_x == m else nums1[partition_x]
            
            max_left_y = -float('inf') if partition_y == 0 else nums2[partition_y - 1]
            min_right_y = float('inf') if partition_y == n else nums2[partition_y]
            
            if max_left_x <= min_right_y and max_left_y <= min_right_x:
                if (m + n) % 2 == 1:
                    return float(max(max_left_x, max_left_y))
                else:
                    return (max(max_left_x, max_left_y) + min(min_right_x, min_right_y)) / 2.0
            elif max_left_x > min_right_y:
                high = partition_x - 1
            else:
                low = partition_x + 1
                
        return 0.0

[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Your Sorting Approach:
- Time Complexity: O((m + n) log(m + n)) — Due to sorting the combined array.
- Space Complexity: O(m + n) Auxiliary Space — Storing all elements in the temporary vector.

Optimal Binary Search Partition Approach:
- Time Complexity: O(log(min(m, n))) — Binary search is performed exclusively on the smaller array.
- Space Complexity: O(1) Auxiliary Space — Uses only a few pointer variables.
