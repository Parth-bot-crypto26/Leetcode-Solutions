LEETCODE 3345: SMALLEST DIVISIBLE DIGIT PRODUCT I
===================================================================

[PROBLEM DESCRIPTION]
You are given two integers `n` and `t`. Return the smallest number greater than 
or equal to `n` such that the product of its digits is divisible by `t`.

Constraints & Notes:
- `1 <= n <= 100`
- `1 <= t <= 10`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation is clean, straightforward, and 100% correct!

1. BRUTE-FORCE SIMULATION WITH DIGIT EXTRACTION:
   - Given the very small constraints ($n \le 100$), iterating upwards starting from `n` 
     and checking each number's digit product is extremely fast and well within time limits.
   - For each number `curr`, you extract its digits using modulo (`temp % 10`) and division (`temp /= 10`), 
     multiplying them together to compute `prod`.
   - If `prod % t == 0`, you immediately return `curr`.

2. EDGE CASE NOTE (Digit 0):
   - Notice that if any digit in `curr` is `0` (e.g., `10`), the product becomes `0`, and since 
     `0 % t == 0` for any non-zero `t`, numbers like `10` successfully satisfy the check.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: n = 15, t = 3

- curr = 15:
  - digits: 1 and 5 -> prod = 1 * 5 = 5.
  - 5 % 3 != 0 -> continue (curr becomes 16).
- curr = 16:
  - digits: 1 and 6 -> prod = 1 * 6 = 6.
  - 6 % 3 == 0 -> condition met! Returns 16.

Final Output: 16

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Brute Force)
class Solution {
public:
    int smallestNumber(int n, int t) {
        int curr = n;
        while (true) {
            int prod = 1;
            int temp = curr;
            while (temp > 0) {
                prod *= (temp % 10);
                temp /= 10;
            }
            if (prod % t == 0) {
                return curr;
            }
            curr++;
        }
    }
};


# Equivalent Python Solution
class Solution:
    def smallestNumber(self, n: int, t: int) -> int:
        curr = n
        while True:
            prod = 1
            temp = curr
            while temp > 0:
                prod *= (temp % 10)
                temp //= 10
            if prod % t == 0:
                return curr
            curr += 1

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(D * K)
  - Where `D` is the number of iterations until a valid number is found (extremely small given $n \le 100$), and `K` is the number of digits in `curr` (at most 3 or 4 digits).

- Space Complexity: O(1) Auxiliary Space
  - Uses only a few local scalar variables (`curr`, `prod`, `temp`).
