===================================================================
LEETCODE 345: REVERSE VOWELS OF A STRING
===================================================================

[PROBLEM DESCRIPTION]
Given a string `s`, reverse only all the vowels in the string and return it.
The vowels are `'a'`, `'e'`, `'i'`, `'o'`, and `'u'`, and they can appear in both 
lower and upper cases.

Constraints & Notes:
- `1 <= s.length <= 3 * 10^5`
- `s` consists of printable ASCII characters.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation using a **two-pointer approach** is **100% optimal, elegant, and textbook-perfect!**

1. TWO-POINTER VOWEL SWAPPING:
   - You initialize two pointers, `left` at the beginning and `right` at the end of the string.
   - The outer `while(left < right)` loop drives them toward each other.
   - The inner loops advance `left` and decrement `right` until both point to valid vowels (checked via `isVowel()`, which handles case-insensitivity cleanly using `tolower()`).
   - Once both pointers land on vowels, you swap them in-place and advance both pointers.

2. EFFICIENCY:
   - This single-pass traversal runs in linear time $O(N)$ with $O(1)$ auxiliary space, perfectly meeting high-performance requirements for large strings up to $3 \times 10^5$ characters.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: s = "IceCreAm"

- left = 0 ('I'), right = 7 ('m')
  - `s[left]` is a vowel ('I'). `s[right]` is not a vowel ('m'), so `right` decrements to 6 ('A').
  - `s[6]` is a vowel ('A').
  - Swap `s[0]` ('I') and `s[6]` ('A'). String becomes `"AceCreIm"`.
  - `left` becomes 1, `right` becomes 5.
- Next iterations advance `left` to 2 ('e') and `right` to 4 ('e'). Swap them (no visible change).
- Pointers cross, loop terminates.

Final Output: `"AceCreIm"`

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Two-Pointer In-Place Swap)
#include <string>
#include <algorithm>
#include <cctype>

class Solution {
    bool isVowel(char c) {
        c = std::tolower(c);
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
    }
public:
    std::string reverseVowels(std::string s) {
        int n = s.length();
        int left = 0, right = n - 1;
        
        while (left < right) {
            while (left < right && !isVowel(s[left])) {
                left++;
            }
            while (left < right && !isVowel(s[right])) {
                right--;
            }
            if (left < right) {
                std::swap(s[left], s[right]);
                left++;
                right--;
            }
        }
        return s;
    }
};


# Equivalent Python Solution
class Solution:
    def reverseVowels(self, s: str) -> str:
        vowels = set("aeiouAEIOU")
        s_list = list(s)
        left, right = 0, len(s_list) - 1
        
        while left < right:
            while left < right and s_list[left] not in vowels:
                left += 1
            while left < right and s_list[right] not in vowels:
                right -= 1
            if left < right:
                s_list[left], s_list[right] = s_list[right], s_list[left]
                left += 1
                right -= 1
                
        return "".join(s_list)

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N)
  - Where `N` is the length of the string `s`. Each character is visited at most once by either the left or right pointer.

- Space Complexity: O(1) Auxiliary Space (C++) / O(N) (Python List Conversion)
  - Modifies the string in-place in C++ without requiring extra data structures.
