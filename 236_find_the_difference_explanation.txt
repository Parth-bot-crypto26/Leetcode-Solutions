===================================================================
LEETCODE 389: FIND THE DIFFERENCE
===================================================================

[PROBLEM DESCRIPTION]
You are given two strings `s` and `t`.
String `t` is generated by randomly shuffling string `s` and then adding one more letter 
at a random position. Return the letter that was added to `t`.

Constraints & Notes:
- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation using the **bitwise XOR operator** is **100% optimal, brilliant, and textbook-perfect!**

1. BITWISE XOR PROPERTY:
   - The XOR operation (`^`) possesses properties of commutativity, associativity, and self-inversion ($x \mathbin{\hat{}} x = 0$ and $x \mathbin{\hat{}} 0 = x$).
   - By XORing every single character in string `s` and then every character in string `t` into a single accumulator (`result`), all characters present in both strings cancel each other out ($x \mathbin{\hat{}} x = 0$).
   - The only remaining character is the single extra letter added to `t` that had no matching pair in `s`.

2. EFFICIENCY:
   - This single-pass traversal runs in strict linear time $O(N)$ (where `N` is the length of `t`) with an optimal $O(1)$ auxiliary memory footprint.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: s = "abcd", t = "abcde"

- Initialize `result = 0`
- XOR all characters of `s`:
  - `result ^= 'a'` -> `0 ^ 'a' = 'a'`
  - `result ^= 'b'` -> `'a' ^ 'b'`
  - `result ^= 'c'` -> `'a' ^ 'b' ^ 'c'`
  - `result ^= 'd'` -> `'a' ^ 'b' ^ 'c' ^ 'd'`
- XOR all characters of `t`:
  - `result ^= 'a'` -> `'a'` cancels out -> `0 ^ 'b' ^ 'c' ^ 'd'`
  - `result ^= 'b'` -> `'b'` cancels out
  - `result ^= 'c'` -> `'c'` cancels out
  - `result ^= 'd'` -> `'d'` cancels out
  - `result ^= 'e'` -> `0 ^ 'e' = 'e'`

Final Output: `'e'`

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Bitwise XOR Approach)
#include <string>

class Solution {
public:
    char findTheDifference(std::string s, std::string t) {
        char result = 0;
        for (char c : s) result ^= c;
        for (char c : t) result ^= c;
        return result;
    }
};


# Equivalent Python Solution
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        result = 0
        for c in s:
            result ^= ord(c)
        for c in t:
            result ^= ord(c)
        return chr(result)

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N)
  - Where `N` is the combined length of strings `s` and `t`. Every character is visited exactly once.

- Space Complexity: O(1) Auxiliary Space
  - Uses a single scalar `char` variable (`result`), requiring constant extra memory regardless of string size.
