===================================================================
LEETCODE 5: LONGEST PALINDROMIC SUBSTRING
===================================================================

[PROBLEM DESCRIPTION]
Given a string `s`, return the longest palindromic substring in `s`.

Constraints & Notes:
- `1 <= s.length <= 1000`
- `s` consists of only digits and English letters.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation using the **expand-around-center approach with a lambda function** is **100% optimal, elegant, and textbook-perfect!**

1. EXPAND AROUND CENTER:
   - A palindrome mirrors around its center, which can be either a single character (for odd-length palindromes) 
     or a space between two characters (for even-length palindromes).
   - By iterating through every possible center index `i` and checking both odd-length (`i, i`) and even-length (`i, i + 1`) expansions, 
     you cover all possible palindromic configurations.
   - The clever index arithmetic `start = i - (len - 1) / 2` accurately tracks the starting index of the longest palindrome found.

2. EFFICIENCY:
   - This approach runs in optimal $O(N^2)$ time complexity with $O(1)$ auxiliary space, entirely avoiding the $O(N^2)$ 
     storage overhead of dynamic programming tables.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: s = "babad" (n = 5)

- i = 0 ('b'):
  - len1 (center 0, 0): expands around 'b' -> length 1
  - len2 (center 0, 1): 'b' vs 'a' -> length 0
  - max len = 1, start = 0
- i = 1 ('a'):
  - len1 (center 1, 1): expands around 'a' -> 'b', 'a', 'b' -> length 3 (`"bab"`)
  - len2 (center 1, 2): 'a' vs 'b' -> length 0
  - `len (3) > maxLength (1)`: `maxLength = 3`, `start = 1 - (3 - 1) / 2 = 0`.
- Continuing through the rest of the string keeps `"bab"` (or finds `"aba"`).

Final Output: `"bab"` (or `"aba"`)

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Expand Around Center)
#include <string>
#include <algorithm>

class Solution {
public:
    std::string longestPalindrome(std::string s) {
        int n = s.length();
        if (n == 0) return "";
        int start = 0, maxLength = 1;
        
        auto expandAroundCenter = [&](int left, int right) {
            while (left >= 0 && right < n && s[left] == s[right]) {
                left--;
                right++;
            }
            return right - left - 1;
        };
        
        for (int i = 0; i < n; ++i) {
            int len1 = expandAroundCenter(i, i);
            int len2 = expandAroundCenter(i, i + 1);
            int len = std::max(len1, len2);
            
            if (len > maxLength) {
                maxLength = len;
                start = i - (len - 1) / 2;
            }
        }
        
        return s.substr(start, maxLength);
    }
};


# Equivalent Python Solution
class Solution:
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        if n == 0:
            return ""
            
        start, max_length = 0, 1
        
        def expand_around_center(left: int, right: int) -> int:
            while left >= 0 and right < n and s[left] == s[right]:
                left -= 1
                right += 1
            return right - left - 1
            
        for i in range(n):
            len1 = expand_around_center(i, i)
            len2 = expand_around_center(i, i + 1)
            length = max(len1, len2)
            
            if length > max_length:
                max_length = length
                start = i - (length - 1) // 2
                
        return s[start:start + max_length]

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N^2)
  - Where `N` is the length of the string `s`. There are $2N - 1$ possible centers, and each center expands outward in linear time.

- Space Complexity: O(1) Auxiliary Space
  - Modulates and tracks indices directly on the input string without auxiliary data structures.
