===================================================================
LEETCODE 1502: CAN MAKE ARITHMETIC PROGRESSION FROM SEQUENCE
===================================================================

[PROBLEM DESCRIPTION]
A sequence of numbers is called an arithmetic progression if the difference between 
any two consecutive elements is the same.
Given an array of numbers `arr`, return `true` if the array can be rearranged to form 
an arithmetic progression. Otherwise, return `false`.

Constraints & Notes:
- `2 <= arr.length <= 1000`
- `-10^6 <= arr[i] <= 10^6`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation using **sorting and linear consecutive difference verification** is **100% optimal, clean, and textbook-perfect!**

1. SORTING & DIFFERENCE CHECKING:
   - To check if elements can form an arithmetic progression when rearranged, sorting them in ascending order is the most direct and reliable approach.
   - Once sorted, any valid arithmetic progression must have a uniform common difference between all consecutive pairs. You establish this expected common difference `diff = arr[1] - arr[0]` and verify that every subsequent adjacent difference matches it.

2. EFFICIENCY:
   - Sorting runs in $O(N \log N)$ time, and the subsequent linear scan runs in $O(N)$ time, requiring $O(\log N)$ or $O(1)$ auxiliary memory space depending on the sorting implementation.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: arr = [3, 5, 1]

- Sort `arr`: `[1, 3, 5]`
- Compute initial difference: `diff = arr[1] - arr[0] = 3 - 1 = 2`
- Iterate from `i = 2`:
  - `i = 2` (`arr[2] = 5`): `arr[2] - arr[1] = 5 - 3 = 2`. Matches `diff`.
- Loop completes without discrepancies.

Final Output: `true`

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Sorting + Linear Scan)
#include <vector>
#include <algorithm>

class Solution {
public:
    bool canMakeArithmeticProgression(std::vector<int>& arr) {
        std::sort(arr.begin(), arr.end());
        int diff = arr[1] - arr[0];
        for (int i = 2; i < arr.size(); ++i) {
            if (arr[i] - arr[i - 1] != diff) {
                return false;
            }
        }
        return true;
    }
};


# Equivalent Python Solution
class Solution:
    def canMakeArithmeticProgression(self, arr: list[int]) -> bool:
        arr.sort()
        diff = arr[1] - arr[0]
        for i in range(2, len(arr)):
            if arr[i] - arr[i - 1] != diff:
                return False
        return True

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

- Time Complexity: O(N \log N)
  - Where `N` is the length of `arr`. Dominated by the sorting step, followed by an efficient $O(N)$ linear pass.

- Space Complexity: O(\log N) or O(N) Auxiliary Space
  - Space required by the sorting algorithm (`std::sort` in C++ typically uses introspective sort requiring $O(\log N)$ stack space).
