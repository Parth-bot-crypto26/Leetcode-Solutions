LEETCODE 4039: SUM OF DECODED NUMBERS
===================================================================

[PROBLEM DESCRIPTION]
You are given an integer array `nums`. Each `nums[i]` is an encoded integer representing two positive integers `x_i` and `y_i`:
- `width_i = nums[i] % 10`
- `d_i = floor(nums[i] / 10)`
- `x_i` is the integer formed by the first `width_i` digits of the decimal representation of `d_i`.
- `y_i` is the integer formed by all remaining digits of the decimal representation of `d_i`.

The decoded value of `nums[i]` is $x_i^{y_i}$.
Return the sum of the decoded values of all elements in `nums`, modulo $10^9 + 7$.

Constraints & Notes:
- `1 <= nums.length <= 10^5`
- `100 < nums[i] < 10^15`
- `1 <= width_i <= 9`
- `1 <= x_i, y_i < 10^9`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your Python implementation using **string slicing, conversion, and modular exponentiation** is **100% optimal, remarkably clean, and completely bulletproof!**

1. DECODING VIA STRING SLICING:
   - Extracting `width` (`w = num % 10`) and base `d` (`d = num // 10`) cleanly isolates the encoded components.
   - Converting `d` to a string (`dStr = str(d)`) allows instantaneous extraction of `x` (`int(dStr[:w])`) and `y` (`int(dStr[w:])`) via standard Python string slicing.
   - Python's built-in `pow(x, y, MOD)` computes modular exponentiation efficiently in $O(\log Y)$ time, seamlessly preventing integer overflow or performance bottlenecks.

2. EFFICIENCY:
   - String conversions and slicing on numbers with at most 14 digits execute in constant time $O(L)$ (where $L \le 14$).
   - Summing and accumulating with modulo operations across `N` elements runs in optimal linear time $O(N)$ with minimal memory overhead.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [231]

- `num = 231`:
  - `w = 231 % 10 = 1`
  - `d = 231 // 10 = 23`
  - `dStr = "23"`
  - `x = int("23"[:1]) = 2`
  - `y = int("23"[1:]) = 3`
  - Decoded value: `pow(2, 3, 1000000007) = 8`
- Total sum = `8`

Final Output: `8`

-------------------------------------------------------------------
[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

# Python Solution (Your Code - Optimal String Parsing & Modular Pow)
class Solution:
    def sumDecoded(self, nums: list[int]) -> int:
        MOD = 10**9 + 7
        total = 0
        for num in nums:
            w = num % 10
            d = num // 10
            d_str = str(d)
            x = int(d_str[:w])
            y = int(d_str[w:])
            total = (total + pow(x, y, MOD)) % MOD
        return total


// Equivalent C++ Solution
#include <vector>
#include <string>
#include <cmath>

class Solution {
    long long power(long long base, long long exp, long long mod) {
        long long res = 1;
        base %= mod;
        while (exp > 0) {
            if (exp % 2 == 1) res = (res * base) % mod;
            base = (base * base) % mod;
            exp /= 2;
        }
        return res;
    }
public:
    int sumDecoded(std::vector<long long>& nums) {
        long long MOD = 1e9 + 7;
        long long total = 0;
        for (long long num : nums) {
            long long w = num % 10;
            long long d = num / 10;
            std::string dStr = std::to_string(d);
            
            long long x = std::stoll(dStr.substr(0, w));
            long long y = std::stoll(dStr.substr(w));
            
            total = (total + power(x, y, MOD)) % MOD;
        }
        return total;
    }
};

- Space Complexity: O(1) Auxiliary Space (ignoring string storage)
  - Uses scalar accumulation variables and short-lived string representations, requiring constant extra memory.
