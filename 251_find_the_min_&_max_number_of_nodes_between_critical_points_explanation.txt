===================================================================
LEETCODE 2058: FIND THE MINIMUM AND MAXIMUM NUMBER OF NODES BETWEEN CRITICAL POINTS
===================================================================

[PROBLEM DESCRIPTION]
A **critical point** in a linked list is either a **local maxima** or a **local minima**:
- A node is a local maxima if its value is strictly greater than both its previous and next nodes.
- A node is a local minima if its value is strictly smaller than both its previous and next nodes.
- (Note: Head and tail nodes cannot be critical points since they lack a previous or next node respectively).

Given the `head` of a linked list, return an array of length 2 containing `[minDistance, maxDistance]`:
- `minDistance`: The minimum distance between any two **distinct** critical points.
- `maxDistance`: The distance between the **first** and **last** critical points.
If there are fewer than two critical points, return `[-1, -1]`.

Constraints & Notes:
- The number of nodes in the list is in the range `[2, 10^5]`.
- `1 <= Node.val <= 10^5`

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation using **single-pass pointer traversal and index tracking** is **100% optimal, remarkably clean, and textbook-perfect!**

1. SINGLE-PASS TRAVERSAL & CRITICAL POINT DETECTION:
   - You maintain a sliding pointer window (`prev`, `curr`, `curr->next`) along with an index tracker `idx` starting at `2` (since the first node cannot be a critical point).
   - For each node, you check the local maxima / minima condition.
   - If a critical point is found:
     - If it is the first one (`first_cp == -1`), you record `first_cp = idx`.
     - Otherwise, you update `min_dist = min(min_dist, idx - last_cp)` to capture the shortest gap between consecutive critical points.
     - You continuously update `last_cp = idx`.

2. BOUNDARY & ERROR HANDLING:
   - Checking `!head || !head->next || !head->next->next` correctly filters lists too short to contain critical points.
   - Validating `if (first_cp == -1 || first_cp == last_cp)` correctly ensures that `[-1, -1]` is returned if there is only 1 or 0 critical points.
   - Finally, `last_cp - first_cp` correctly computes the maximum distance between the first and last critical points.

3. EFFICIENCY:
   - This approach runs in a single linear pass of $O(N)$ time complexity and requires strict $O(1)$ auxiliary memory space, entirely bypassing the need to store indices in a vector.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: head = [5, 3, 1, 2, 5, 1, 2]

- `idx = 2`: `curr = 3` (prev = 5, next = 1) $\to$ not a critical point.
- `idx = 3`: `curr = 1` (prev = 3, next = 2) $\to$ **Local Minima** (`1 < 3` and `1 < 2`).
  - `first_cp` was `-1` $\to$ sets `first_cp = 3`, `last_cp = 3`.
- `idx = 4`: `curr = 2` (prev = 1, next = 5) $\to$ not a critical point.
- `idx = 5`: `curr = 5` (prev = 2, next = 1) $\to$ **Local Maxima** (`5 > 2` and `5 > 1`).
  - `first_cp` is 3 (not `-1`). `min_dist = min(inf, 5 - 3) = 2`. `last_cp = 5`.
- `idx = 6`: `curr = 1` (prev = 5, next = 2) $\to$ **Local Minima** (`1 < 5` and `1 < 2`).
  - `min_dist = min(2, 6 - 5) = 1`. `last_cp = 6`.
- Loop ends (`curr->next == nullptr`).

Result: `[min_dist, last_cp - first_cp] = [1, 6 - 3] = [1, 3]`.

Final Output: `[1, 3]`

[C++ & PYTHON IMPLEMENTATIONS]
-------------------------------------------------------------------

// C++ Solution (Your Code - Optimal Single-Pass Pointer Traversal)
#include <vector>
#include <algorithm>
#include <climits>

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    std::vector<int> nodesBetweenCriticalPoints(ListNode* head) {
        if (!head || !head->next || !head->next->next) return {-1, -1};
        
        ListNode* prev = head;
        ListNode* curr = head->next;
        int idx = 2;
        int first_cp = -1;
        int last_cp = -1;
        int min_dist = 1e9;
        
        while (curr->next != nullptr) {
            if ((curr->val > prev->val && curr->val > curr->next->val) ||
                (curr->val < prev->val && curr->val < curr->next->val)) {
                if (first_cp == -1) {
                    first_cp = idx;
                } else {
                    min_dist = std::min(min_dist, idx - last_cp);
                }
                last_cp = idx;
            }
            prev = curr;
            curr = curr->next;
            idx++;
        }
        
        if (first_cp == -1 || first_cp == last_cp) {
            return {-1, -1};
        }
        
        return {min_dist, last_cp - first_cp};
    }
};


# Equivalent Python Solution
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def nodesBetweenCriticalPoints(self, head: Optional[ListNode]) -> List[int]:
        if not head or not head.next or not head.next.next:
            return [-1, -1]
            
        prev = head
        curr = head.next
        idx = 2
        first_cp = -1
        last_cp = -1
        min_dist = float('inf')
        
        while curr.next is not None:
            if (curr.val > prev.val and curr.val > curr.next.val) or \
               (curr.val < prev.val and curr.val < curr.next.val):
                if first_cp == -1:
                    first_cp = idx
                else:
                    min_dist = min(min_dist, idx - last_cp)
                last_cp = idx
                
            prev = curr
            curr = curr.next
            idx += 1
            
        if first_cp == -1 or first_cp == last_cp:
            return [-1, -1]
            
        return [min_dist, last_cp - first_cp]
