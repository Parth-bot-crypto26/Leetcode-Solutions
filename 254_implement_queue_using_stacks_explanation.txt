[PROBLEM DESCRIPTION]
Implement a first-in, first-out (FIFO) queue using only two stacks. The implemented 
queue should support all standard queue operations: `push`, `pop`, `peek`, and `empty`.

Operations:
- `void push(int x)`: Pushes element `x` to the back of the queue.
- `int pop()`: Removes and returns the element from the front of the queue.
- `int peek()`: Returns the element at the front of the queue.
- `boolean empty()`: Returns `true` if the queue is empty, `false` otherwise.

Constraints & Notes:
- You must use **only standard operations of a stack** (push to top, peek/pop from top, size, empty).
- At most 100 calls will be made to `push`, `pop`, `peek`, and `empty`.

-------------------------------------------------------------------
[METHODOLOGY & CRITIQUE OF YOUR APPROACH]
-------------------------------------------------------------------

Your C++ implementation using **push-time reordering with two stacks** is **100% correct, functional, and successfully passes all test cases!**

1. PUSH-TIME REORDERING CRITIQUE:
   - In your code, you push the new element to the back of the queue by moving everything to `s2`, inserting `x` into `s1`, and moving everything back. This keeps `pop()` and `peek()` operating in strict $O(1)$ time because the front of the queue is always at the top of `s1`.
   - However, each `push(x)` operation takes $O(N)$ time because all existing elements are shifted twice.

2. AMORTIZED O(1) OPTIMAL FOLLOW-UP APPROACH:
   - To achieve **amortized $O(1)$ time complexity** for *every* operation (as requested by the follow-up), we can divide responsibilities between an **input stack (`sInput`)** and an **output stack (`sOutput`)**:
     - **`push(x)`**: Always push directly onto `sInput` in $O(1)$ time.
     - **`pop()` / `peek()`**: If `sOutput` is empty, pour all elements from `sInput` into `sOutput`. This reverses their order, perfectly aligning them into FIFO sequence. Then pop or peek from `sOutput` in $O(1)$ time.
   - Because each element is pushed and popped from each stack at most once across its lifecycle, the amortized cost per operation drops to $O(1)$!

-------------------------------------------------------------------
[DRY RUN EXAMPLE (Amortized O(1) Approach)]
-------------------------------------------------------------------
Operations: `push(1)`, `push(2)`, `peek()`, `pop()`

- `push(1)`: `sInput` = `[1]`, `sOutput` = `[]`
- `push(2)`: `sInput` = `[1, 2]`, `sOutput` = `[]`
- `peek()`:
  - `sOutput` is empty $\to$ transfer all from `sInput` to `sOutput`.
  - `sInput` becomes `[]`, `sOutput` becomes `[2, 1]` (with `1` at the top).
  - Returns `sOutput.top()` which is `1`.
- `pop()`:
  - `sOutput` is not empty $\to$ pops `1` directly from `sOutput`. (`sOutput` = `[2]`).

Final Output: `[null, null, null, 1, 1, false]`

// C++ Solution (Your Code - Push-Time Reordering)
#include <stack>

class MyQueuePushHeavy {
public:
    std::stack<int> s1;
    std::stack<int> s2;
    MyQueuePushHeavy() {}
    
    void push(int x) {
        while (!s1.empty()) {
            s2.push(s1.top());
            s1.pop();
        }
        s1.push(x);
        while (!s2.empty()) {
            s1.push(s2.top());
            s2.pop();
        }
    }
    
    int pop() {
        int ans = s1.top();
        s1.pop();
        return ans;
    }
    
    int peek() {
        return s1.top();
    }
    
    bool empty() {
        return s1.empty();
    }
};


// C++ Solution (Amortized O(1) Optimal Two-Stack Approach)
class MyQueue {
    std::stack<int> sInput;
    std::stack<int> sOutput;

    void transfer() {
        while (!sInput.empty()) {
            sOutput.push(sInput.top());
            sInput.pop();
        }
    }

public:
    MyQueue() {}
    
    void push(int x) {
        sInput.push(x);
    }
    
    int pop() {
        if (sOutput.empty()) {
            transfer();
        }
        int ans = sOutput.top();
        sOutput.pop();
        return ans;
    }
    
    int peek() {
        if (sOutput.empty()) {
            transfer();
        }
        return sOutput.top();
    }
    
    bool empty() {
        return sInput.empty() && sOutput.empty();
    }
};


# Equivalent Python Solution (Amortized O(1) Approach)
class MyQueue:
    def __init__(self):
        self.s_input = []
        self.s_output = []

    def push(self, x: int) -> None:
        self.s_input.append(x)

    def _transfer(self) -> None:
        while self.s_input:
            self.s_output.append(self.s_input.pop())

    def pop(self) -> int:
        if not self.s_output:
            self._transfer()
        return self.s_output.pop()

    def peek(self) -> int:
        if not self.s_output:
            self._transfer()
        return self.s_output[-1]

    def empty(self) -> bool:
        return not self.s_input and not self.s_output
