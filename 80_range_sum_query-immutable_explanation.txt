===================================================================
LEETCODE 303: RANGE SUM QUERY - IMMUTABLE
===================================================================

[PROBLEM DESCRIPTION]
Design a data structure that accepts an integer array 'nums' and handles 
multiple range sum queries.

Implement the NumArray class:
- NumArray(int[] nums): Initializes the object with the integer array 'nums'.
- int sumRange(int left, int right): Returns the sum of elements between indices 
  'left' and 'right' inclusive (nums[left] + ... + nums[right]).

Constraints:
- 1 <= nums.length <= 10^4
- At most 10^4 calls will be made to 'sumRange'.

-------------------------------------------------------------------
[METHODOLOGY: 1-INDEXED PREFIX SUM PRECOMPUTATION (O(1) QUERY)]
-------------------------------------------------------------------

Summing elements iteratively on every 'sumRange' call results in an O(N) runtime 
per query, leading to Time Limit Exceeded (TLE) over 10^4 calls. 

We achieve instant O(1) query performance using the **Prefix Sum Array** pattern:

1. 1-INDEXED PREFIX ARRAY ARCHITECTURE:
   - We maintain a dynamic array 'pref' where 'pref[i]' stores the cumulative sum 
     of the first 'i' elements of 'nums'.
   - By seeding 'pref[0] = 0', 'pref[i]' maps directly to the sum of elements 
     from index 0 up to 'i - 1'.

2. PRECOMPUTATION (Constructor):
   - We iterate through 'nums' once during initialization, populating the prefix array:
     'pref.push_back(pref.back() + num);'
   - This builds the cumulative sum array in linear O(N) time.

3. CONSTANT TIME RANGE EXTRACTION (sumRange):
   - To find the sum of range [left, right], we compute:
     Formula: pref[right + 1] - pref[left]
   - 'pref[right + 1]' represents the sum of elements from index 0 to 'right'.
   - 'pref[left]' represents the sum of elements from index 0 to 'left - 1'.
   - Subtracting 'pref[left]' leaves precisely the subarray sum from 'left' to 'right'.
   - The 0-index offset automatically handles cases where 'left == 0' without conditional branching.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input Array: nums = [-2, 0, 3, -5, 2, -1]

- Constructor Execution:
  pref[0] = 0
  pref[1] = 0 + (-2) = -2
  pref[2] = -2 + 0   = -2
  pref[3] = -2 + 3   = 1
  pref[4] = 1 + (-5)  = -4
  pref[5] = -4 + 2   = -2
  pref[6] = -2 + (-1) = -3
  pref = [0, -2, -2, 1, -4, -2, -3]

- Query 1: sumRange(0, 2)
  Calculation: pref[3] - pref[0] = 1 - 0 = 1.

- Query 2: sumRange(2, 5)
  Calculation: pref[6] - pref[2] = -3 - (-2) = -1.

- Query 3: sumRange(0, 5)
  Calculation: pref[6] - pref[0] = -3 - 0 = -3.

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity:
- Constructor: O(n)
  * Explanation: Precomputes the cumulative sum array in a single linear pass over 'nums'.
- sumRange Query: O(1)
  * Explanation: Performs a single subtraction operation between two array lookups, 
    executing in true constant time.

Space Complexity: O(n)
- Explanation: Allocates an auxiliary vector 'pref' of size 'n + 1' to store cumulative sums.
