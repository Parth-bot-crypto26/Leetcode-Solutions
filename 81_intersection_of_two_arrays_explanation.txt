===================================================================
LEETCODE 349: INTERSECTION OF TWO ARRAYS
===================================================================

[PROBLEM DESCRIPTION]
Given two integer arrays 'nums1' and 'nums2', return an array of their 
intersection. Each element in the result must be unique and may be returned 
in any order.

Constraints:
- 1 <= nums1.length, nums2.length <= 1000
- 0 <= nums1[i], nums2[i] <= 1000

-------------------------------------------------------------------
[METHODOLOGY: DUAL HASH SET INTERSECTION FILTER (O(N + M))]
-------------------------------------------------------------------

A brute-force solution comparing every pair between nums1 and nums2 runs in O(N * M) 
time complexity. We optimize this to linear average runtime using hash sets:

1. DEDUPLICATION & LOOKUP TABLE INITIALIZATION:
   - We construct an 'unordered_set<int>' ('set1') directly from 'nums1'.
   - This automatically removes duplicates from 'nums1' while providing O(1) 
     average lookup time for membership checks.

2. INTERSECTION MATCHING:
   - We iterate through each element 'num' in 'nums2'.
   - If 'set1.count(num)' is true, 'num' is present in both arrays. We insert it 
     into a second hash set ('intersectionSet').
   - Using a second set ensures that duplicate values within 'nums2' do not create 
     duplicate entries in the result.

3. CONTAINER CONVERSION:
   - We construct and return a 'vector<int>' initialized directly with the range 
     iterators '[intersectionSet.begin(), intersectionSet.end()]'.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums1 = [4, 9, 5], nums2 = [9, 4, 9, 8, 4]

- Step 1: Build set1 from nums1
  set1 = {4, 9, 5}

- Step 2: Scan nums2
  * num = 9: in set1? Yes -> insert to intersectionSet = {9}
  * num = 4: in set1? Yes -> insert to intersectionSet = {9, 4}
  * num = 9: in set1? Yes -> set prevents duplicate, intersectionSet = {9, 4}
  * num = 8: in set1? No  -> skip
  * num = 4: in set1? Yes -> set prevents duplicate, intersectionSet = {9, 4}

- Step 3: Convert intersectionSet to vector
  Returns [9, 4] (or [4, 9]).

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n + m)
- Explanation: Where 'n' is the length of 'nums1' and 'm' is the length of 'nums2'. 
  Constructing 'set1' takes O(n) average time. Traversing 'nums2' takes O(m) time with 
  O(1) set operations per item.

Space Complexity: O(n + m)
- Explanation: In the worst-case scenario, 'set1' stores 'n' elements, and 
  'intersectionSet' stores up to min(n, m) elements, resulting in linear space overhead.
