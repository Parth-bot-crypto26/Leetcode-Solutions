===================================================================
LEETCODE 3300: MINIMUM ELEMENT AFTER REPLACEMENT WITH DIGIT SUM
===================================================================

[PROBLEM DESCRIPTION]
You are given an integer array 'nums'. Replace each element in 'nums' with the sum 
of its digits. Return the minimum element in 'nums' after all replacements.

Constraints:
- 1 <= nums.length <= 100
- 1 <= nums[i] <= 10^4

-------------------------------------------------------------------
[METHODOLOGY: STREAMING DIGIT SUM & RUNNING MINIMUM TRACKING (O(N))]
-------------------------------------------------------------------

Instead of mutating the input array 'nums' or allocating a new vector to hold 
the transformed values (which adds unnecessary memory operations), we can process 
each value in a single streaming pass:

1. DIGIT SUM REDUCTION:
   - We write a helper function 'getDigitSum(n)' that extracts digits using 
     modulo arithmetic ('n % 10') and integer division ('n /= 10') until 'n == 0'.
   - Given 'nums[i] <= 10000', any integer in 'nums' has at most 5 decimal digits, 
     making this reduction step execute in at most 5 operations per number.

2. RUNNING MINIMUM ACCUMULATION:
   - We initialize 'min_sum = INT_MAX'.
   - As we iterate through each 'num' in 'nums', we compute its digit sum 
     'current = getDigitSum(num)'.
   - We update 'min_sum' dynamically: 'min_sum = min(min_sum, current)'.

3. SPACE EFFICIENCY:
   - Evaluated on-the-fly without modifying the underlying vector or allocating auxiliary arrays.

-------------------------------------------------------------------
[DRY RUN EXAMPLE]
-------------------------------------------------------------------
Input: nums = [999, 19, 199]

Initial State: min_sum = INT_MAX

- num = 999: current = 9 + 9 + 9 = 27
             min_sum = min(INT_MAX, 27) = 27
- num = 19:  current = 1 + 9 = 10
             min_sum = min(27, 10) = 10
- num = 199: current = 1 + 9 + 9 = 19
             min_sum = min(10, 19) = 10

Loop terminates.
Returns 10.

-------------------------------------------------------------------
[COMPLEXITY ANALYSIS]
-------------------------------------------------------------------

Time Complexity: O(n * log10(M))
- Explanation: Where 'n' is the number of elements in 'nums' and 'M' is the maximum value 
  in 'nums'. Since 'M <= 10^4', log10(M) <= 5, running the algorithm in O(n) linear time.

Space Complexity: O(1)
- Explanation: Uses only a few scalar variables ('min_sum', 'current', 'sum') on the stack, 
  requiring zero dynamic memory allocation.
